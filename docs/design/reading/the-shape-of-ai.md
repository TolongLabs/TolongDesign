## What it is

The Shape of AI is an interactive UX pattern library curated and written by
Emily Campbell. It is designed to bring structure, taxonomy, and proven
cognitive heuristics to artificial intelligence interfaces. Recognizing that
software teams often rush to implement generative AI without clear UX
conventions, the project maps out how humans and algorithmic models collaborate
effectively.

The library categorizes emerging AI interaction paradigms into six core pattern
types:

- **Wayfinders:** Navigation and orientation mechanisms that guide users through
  open-ended generative workflows.
- **Inputs:** Structured prompt fields, attachments, voice controls, and
  multimodal submission interfaces.
- **Tuners:** Controls for calibrating model temperature, style, tone, format,
  and constraints.
- **Trust Builders:** Citations, cost estimates, caveats, disclosures, and data
  ownership guarantees that establish confidence.
- **Governors:** Safety guardrails, permission boundaries, and confirmation
  steps.
- **Identifiers:** Clear labeling of synthetic content, generative avatars, and
  system status.

Each documented pattern includes real-world product screenshots, interaction
breakdowns, rationale, and usability trade-offs.

## Paywall and pricing

- **Free:** The complete pattern catalog, breakdowns, Substack newsletter, and
  community Slack group are entirely free to access.
- **Paid:** None. There are no paid subscriptions or paywalled pattern tiers.
- **Sign-up required?** No account is required to browse the web catalog. An

  the underlying interaction concepts and UX structures to commercial client

## How to use

1. Audit client AI feature briefs against the pattern catalog: determine whether
   the feature requires Wayfinders (guidance), Tuners (calibration), or Trust
   Builders (provenance and citations).
2. Choose specific interaction patterns: for example, when designing an AI
   search or document summarizer, implement the _Citations_ pattern
   (`https://www.shapeof.ai/patterns/citations`) to anchor outputs in source
   material.
3. Design prompt ergonomics: review the _Inputs_ collection to avoid blank text
   boxes, incorporating suggestion chips and structured form controls.
4. Integrate trust and governance: review the _Cost Estimates_ and _Caveat_
   patterns to ensure users understand token usage and model limitations before
   triggering expensive background tasks.

  reference material.

## When to use it

- Use it when designing applications powered by LLMs or generative models,
  ensuring interactions go beyond basic chat box text interfaces.
- Use it to plan trust, citation, and error-handling mechanisms for client SaaS
  products integrating AI features.
- Skip it if you need general usability heuristics unrelated to AI; consult
  [Laws of UX](../reading/laws-of-ux.md) instead.
- Skip it if you are looking for ready-to-use React components; use component
  libraries instead.

## Agent notes

- Not agent-friendly: The Shape of AI is an editorial Webflow publication
  focused on visual UI critique and conceptual interaction patterns.
- AI coding agents can reference the documented taxonomies (Wayfinders, Tuners,
  Trust Builders, Citations) when proposing UI architectures or prompt-input
  components in planning documents.
