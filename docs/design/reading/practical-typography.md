## What it is

Practical Typography is Matthew Butterick's online book about type, layout, and
publishing. It covers general typography rules and includes chapters
specifically about web pages and type on screens.

The book is freely available to read online and is supported by optional reader
payments. The site also sells fonts separately; those assets have their own
purchase and licensing terms.

Use it to make informed decisions about text hierarchy, punctuation, line
length, font pairing, and reading comfort. It is especially useful when a web
page has substantial editorial or product copy.

## Paywall and pricing

- The online book is free to read. The author invites optional support payments
  of $19, $29, $39, or $49.
- Custom fonts are sold separately; the homepage lists font prices starting at
  $119.
- No account is required to read the online book. Purchased fonts have separate
  licensing terms for commercial and client work.
- The text and font assets are copyrighted; no open-content license is published
  for the book.

Checked 2026-10-07. Prices can change; use the linked official page for current
terms.

## How to use

- Browse the table of contents or use the book's search to find a topic such as
  line length, quotation marks, or web typography.
- Apply one guideline at a time to real content rather than treating a type
  specimen as a complete page design.
- Check line length and spacing at the intended viewport, with actual copy and
  user-adjustable text settings.
- If choosing a paid font, read its license and confirm the client project is
  covered before embedding it.

## When to use it

- Use it for editorial pages, marketing copy, product text, and design-system
  rules that need legible defaults.
- Skip it when you need current browser implementation details; use web.dev for
  platform guidance.

## Agent notes

- The book is plain public web content rather than an API or package.
- Use the guidance to inform CSS decisions, but check contrast, zoom, responsive
  behavior, and user preferences in the implementation.
- Do not redistribute the book text or font files as project assets without
  permission.
- Prices and font licensing may change; check the official site before purchase.
