## What it is

Josh Comeau publishes interactive technical tutorials about CSS, JavaScript,
React, animation, and browser behavior. Many articles use small live demos to
make an otherwise abstract behavior visible.

The site also sells structured courses, including CSS for JavaScript Developers
and Joy of React. Free articles and demos are useful for focused learning; paid
courses provide longer curricula and exercises.

This is a technical learning resource, not a design system or component package.
Follow an example to understand a mechanism, then adapt it to the product rather
than copying a demo wholesale.

## How to use

- Browse by topic or search for the CSS, React, or animation behavior you need
  to understand.
- Read the explanation and interact with the demos; change one variable at a
  time to observe cause and effect.
- Adapt the smallest relevant code idea to the project's framework and
  constraints, then verify it in the target browsers.
- Use the course curriculum when the team needs a structured learning path
  beyond a single article.

## When to use it

- Use it when a developer needs a clear mental model for CSS, React, or
  animation behavior and can benefit from an interactive demo.
- Skip it for team-wide component governance or formal accessibility patterns;
  use Inclusive Components for accessible interaction guidance.

## Agent notes

- Public articles contain code and live examples, but confirm browser support
  before relying on newer CSS features.
- Course materials are paid and copyrighted; do not assume access to gated
  content from a public article.
- Use examples as focused demonstrations. Check reduced-motion preferences,
  keyboard use, and project style constraints in the final implementation.
- The official courses page is the source for current curriculum and pricing.
