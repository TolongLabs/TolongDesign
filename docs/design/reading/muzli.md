## What it is

Muzli is a widely adopted design inspiration aggregator founded by Eyal Zuri and
Ohad Kravchick. Delivered primarily as a browser new-tab extension and a web
app, it aggregates and curates visual design work, UI concepts, illustrations,
and tech news from hundreds of online design communities, including Dribbble,
Behance, Awwwards, Product Hunt, and independent portfolios.

The core premise of Muzli is ambient discovery: every time a designer or
developer opens a new browser tab, they are presented with a curated stream of
top-ranked design assets, brand identity case studies, UI interactions, and
industry articles. This eliminates the friction of manually visiting disparate
design aggregators.

Beyond the aggregation feed, the platform runs Muzli Blog (`medium.muz.li`),
publishing design roundups, weekly inspiration digests, and practical UX guides
covering typography, optical alignment, and color systems.

## Paywall and pricing

- **Free:** The browser extension (Chrome, Safari, Edge, Firefox) and basic web
  feed at `muz.li` are free to install and use indefinitely. Users can view the
  default curation stream, search by keyword, and browse trending projects.
- **Paid:** Muzli Pro is available for advanced customization:
  - **Monthly:** $9/month.
  - **Annual:** $5/month ($60 billed annually).
  - **Lifetime:** $350 one-time payment.
  - Pro features include an ad-free interface, access across mobile browsers,
    custom feed curation selecting from over 200 sources, priority design
    submission credits, and a verified profile badge.
- **Sign-up required?** No for installing and using the basic free browser
  extension. Yes for creating custom collections, syncing preferences across
  devices, or upgrading to Muzli Pro.
- **Licence for client work:** Displayed artwork and interfaces belong to their
  respective authors. They serve as mood board references and aesthetic
  benchmarks; direct replication without permission is prohibited.

Verified on the official Muzli website and pricing portal on 2026-10-07.

## How to use

1. Install the browser extension: Add Muzli to your primary workstation browser
   so that each new tab presents the latest curated digital projects.
2. Filter by source or category: In the feed sidebar, filter entries by tags
   such as UI/UX, Web, Illustration, or specific platforms (like Dribbble or
   Awwwards) to find relevant visual references.
3. Curate project mood boards: Bookmark relevant interface shots, color schemes,
   and visual trends to a project collection for client alignment workshops.
4. Read weekly deep dives: Check the Muzli Blog (`https://medium.muz.li/`) for
   curated weekly roundups and educational design principles.

## When to use it

- Use it as an ambient inspiration tool for product designers and frontend
  developers who want effortless exposure to current design trends.
- Use it during client discovery phases to quickly gather contemporary visual
  mood board references.
- Skip it when you need in-depth technical tutorials or code implementations;
  consult [Smashing Magazine](../reading/smashing-magazine.md) or
  [Codrops](../reading/codrops.md) instead.

## Agent notes

- Non-machine-readable: Muzli does not expose a public developer API, CLI, or
  `llms.txt` endpoint.
- Aggregated content links out to external source URLs (Dribbble, Behance,
  independent studio sites), which may require independent web extraction.
- The web app relies on client-side rendering for its endless scroll feed.
