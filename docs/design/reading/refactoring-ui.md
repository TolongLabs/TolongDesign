## What it is

Refactoring UI is a practical interface-design package by Adam Wathan and Steve
Schoger. It teaches visual decisions from a developer's point of view through a
book, videos, a component gallery, and design assets.

The material focuses on hierarchy, spacing, typography, color, forms,
dashboards, and other common interface problems. The homepage publishes a table
of contents and sample chapters, while the complete package is paid.

Use it as a set of concrete visual heuristics while building a UI. It teaches
ways to reason about layout and visual polish; it is not a component library or
a substitute for testing a real product with users.

## How to use

- Start with the free sample and table of contents to identify a relevant topic
  such as hierarchy, spacing, or text styling.
- Read the related section before implementing the screen; write down the
  specific design decision it informs.
- Use the tutorials and gallery to compare patterns, then adapt them to the
  product's content, brand, and accessibility requirements.
- Treat its suggestions as design guidance rather than fixed rules; check the
  result at actual content lengths and responsive sizes.

## When to use it

- Use it when a developer needs a systematic way to make a web interface clearer
  and more visually finished.
- Skip it when the task needs implementation-ready components or accessibility
  specifications; use Inclusive Components for accessible patterns.
