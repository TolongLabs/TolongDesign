## What it is

web.dev publishes guidance, courses, and articles about building for the web.
Topics include performance, accessibility, CSS, browser capabilities, and modern
platform standards.

The site is maintained by Google and contributors. Articles often include code
samples and links to specifications or browser support information, making it
useful for implementation research rather than visual inspiration alone.

No paid tier was found on the pages checked. The site content has no license
statement in the pages reviewed, so confirm reuse rights before reproducing
substantial text or assets.

## How to use

- Search web.dev by API, topic, or problem statement; use the Web Platform
  section for browser capabilities and the Learn area for guided courses.
- Read the article's browser support and implementation notes before choosing an
  API or CSS feature.
- Copy a minimal sample into a small experiment, then check it against the
  project's browser support matrix and accessibility needs.
- Use the article's linked primary references when a product decision depends on
  exact standards behavior.

## When to use it

- Use it when implementation depends on modern browser APIs, performance
  techniques, or web accessibility guidance.
- Skip it for visual references or conversion research; use Refactoring UI,
  Design Spells, or Good UI for those.

## Agent notes

- Articles include implementation examples that a coding agent can adapt after
  checking the project's framework and browser targets.
- Treat published guidance as a starting point; check linked standards and
  compatibility data for fast-changing features.
- Do not paste full article prose into project documentation; link to the
  original and summarize only what the implementation needs.
- Content license was not confirmed in the checked pages, so avoid reusing
  illustrations or large text excerpts.
