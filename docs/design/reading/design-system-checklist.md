## What it is

Design System Checklist is a public checklist site intended to help teams plan,
build, and grow a design system. Its linked repository describes the project as
an open-source checklist.

The live site presented an app shell with About and Share routes, but the
checklist content itself did not render in the research reader. The repository
was accessible and confirmed the project's stated purpose, but individual
checklist items could not be verified.

The repo did not expose a license file in the pages reviewed. Treat its code as
publicly viewable rather than reusable open-source material until a license is
confirmed.

## How to use

- Open the live checklist and inspect its sections in a full browser; the
  research reader could see the app shell but not the client-rendered checklist.
- Use the repository README to understand the project's stated purpose and
  source structure.
- When the live checklist is available, map items to the team's token,
  component, documentation, accessibility, and governance workstreams.
- Record checklist decisions in the team's own design-system brief rather than
  treating a generic checklist as a completed audit.
