## What it is

Learn UI is an interactive guide to design engineering, with chapters about
subtle details in interface work. The current site presents an online guide
rather than a conventional video-course catalog.

Its chapters discuss motion, consistency, gestures, and other implementation
details through prose and interactive examples. This makes it useful for
connecting visual decisions to front-end behavior.

The site is publicly readable, and no paid course gate or price was found on the
pages checked. The content license was not stated in those pages.

## How to use

- Start from the chapter list and choose a topic that matches the design
  question, such as motion, spatial consistency, or responsive gestures.
- Read the explanation and interact with each demo to see how a small behavior
  changes the perceived interface.
- Translate the lesson into a project-specific design rule or prototype, then
  test it with real content, devices, and reduced-motion settings.
- Use the guide as inspiration and explanation, not as a substitute for the
  product's own accessibility review.

## When to use it

- Use it when designing or implementing subtle interactions and the reasoning
  behind motion or layout details.
- Skip it when the need is a component API or current browser support data; use
  Inclusive Components or web.dev.

## Agent notes
