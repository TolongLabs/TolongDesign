## What it is

UI Land (subtitled "The Digital Library for Designers and Engineers" at
`ui.land`) is a specialized interview publication and resource directory curated
by Emil Kowalski (design engineer at Linear). The platform is dedicated to
exploring the emerging discipline of design engineering through the lens of
individual practitioners.

The core of the platform is a series of in-depth, structured interviews with
prominent design engineers and creative developers who have defined the
aesthetic and interaction standards of modern web products. Each profile
includes:

- **Philosophy of Craft:** Personal reflections on what makes an interface
  delightful, how to balance speed with nuance, and how to avoid generic design.
- **Workstation Stacks:** Exact software, hardware, and IDE tools used by each
  engineer (VS Code, Raycast, Figma, Arc, Obsidian, CleanShot).
- **Key Takeaways & Quotes:** Distilled advice on learning design, sharing work
  in public, and mastering animation nuances.
- **Resource Recommendations:** Curated links to articles, courses, and design
  systems recommended by each interviewee.

Featured interviewees include Rauno Freiberg (Vercel), Paco Coursey (Linear),
Sam Selikoff (Build UI), Nanda Syahrasyad (Vercel/nan.fyi), SJ Zhang (Compound),
and Brotzky (Narative/Fey).

## Paywall and pricing

- **Free:** All interviews, practitioner profiles, and curated resources on
  `ui.land` are 100% free to read without payment or login.
- **Paid:** None. There are no paid tiers or paywalled interviews.
- **Sign-up required?** No. Access to all content is immediate. An optional
  monthly email newsletter is available for readers.
- **Licence for client work:** Editorial interviews and photography are
  copyrighted by UI Land and the interviewees. Workflows, philosophies, and
  tooling setups can be freely adopted by development teams.

Verified on the live UI Land website on 2026-10-07.

## How to use

1. Benchmark design engineering tool stacks: Review interviewee profiles to
   evaluate which developer productivity tools (Raycast extensions, font
   pairings, capture utilities) top design engineers use daily.
2. Inspire team design culture: Read Rauno Freiberg or Paco Coursey's interviews
   with frontend engineering teams to foster an internal culture of "painting
   with code" and sweating micro-details.
3. Discover high-signal resources: Browse the Resources section
   (`https://ui.land/resources`) to discover independent portfolios, personal
   blogs, and design references vetted by leading engineers.
4. Subscribe to the monthly digest: Join the newsletter to receive new interview
   drops and exclusive design engineering links.

## When to use it

- Use it when shaping career ladders or defining the role of a "Design Engineer"
  within an organization.
- Use it for inspiration on how to balance aesthetic taste with deep frontend
  engineering rigor.
- Skip it when you need step-by-step code tutorials or UI component libraries;
  consult [Interfaces](../reading/interfaces.md) or
  [Codrops](../reading/codrops.md) instead.

## Agent notes

- Non-machine-readable: UI Land is a static Next.js website without a public
  API, CLI, or `llms.txt`.
- Data is embedded cleanly in Next.js SSG script tags (`__NEXT_DATA__`), making
  interviews, metadata, and tool stacks easy to extract programmatically.
- Useful for agents to reference when users ask about the tooling stacks and
  philosophies of top-tier design engineers.
