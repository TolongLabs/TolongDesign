# Effect Lines & Screentone Generator

> Free tool that makes manga focus lines, kakeami hatching and screentones.
>
> Reach for it when a page needs speed lines, a halftone tone or a hatched
> shadow and you want the shapes as editable vector files, not a flat render.

## What it is

The Effect Lines & Screentone Generator (効果線・トーンジェネレーター) is a free
browser app by MIYADAIKU (おやすみゲーム開発部, on X as
[@sharp_maker](https://x.com/sharp_maker)). It draws 27 kinds of manga effect
line and tone from sliders, in five groups: focus lines, effect lines,
cross-hatching, tones and mood. Nothing is generated by an image model; every
stroke is computed from a random seed and geometry.

Each of the 27 types is a small generator with its own parameter set. A focus
line has line count, inner radius, inner aspect, width, spacing variation and
"clustering"; a halftone has spacing, density, screen angle and dot shape; a
cross-hatch has bundle size, layer count, flow and solid black. One shared
"seed" string decides the randomness, so the same seed always gives the same
picture.

The preview and the SVG export are drawn from the same geometry, so a saved PNG
and a saved SVG agree shape for shape. Output is layered: you stack up to eight
generators, each with its own colour, opacity and "white areas" behaviour. The
inside of a shape engine is worth knowing about: halftone dots are Euclidean
dots, so 50% density is a checkerboard and past that the white holes shrink,
which makes a gradient cross from black to white without a step. Rope hatch
places bundles along a smooth noise flow field and cuts the lines hidden under
the bundle above by geometry, not by painting white over them, which is why a
rope-hatch SVG keeps only its lines.

It belongs to the author's suite of manga tools, alongside
[Manga Panel Layout Generator](../comics/komawari.md),
[Speech Bubble Generator](../comics/fukidashi.md),
[Name Gacha](../comics/namegacha.md) and
[Comicalizer](../comics/comicalizer.md), which can embed it. The app is a single
self-contained HTML file, about 404 KB, with no framework, no webfont and no
network call except the contact form.

## How to use

The app opens in English when you add `?lang=en`. Labels below are the English
UI; the Japanese label is in parentheses the first time.

1. Open <https://tools.oyasumi-gamedev.com/koukasen/?lang=en>. The stage is on
   the left, the 27 type buttons on the right. The first layer is already a
   Focus lines (集中線) generator with seed `SC-2026`.
2. Pick a type from the grid at the top right. Clicking a type changes the
   **selected layer**, not the whole document. Click **New shape** (別の形, the
   button with the dice icon) for another random shape at the same settings.
   Types that use no random numbers, such as Halftone, do not change and the app
   tells you so.
3. Move the centre by dragging inside the preview. Focus lines, Flash rays,
   Black flash, Urchin flash, Curved lines, Wind, Black edge in circle mode and
   Rope radial/ring all take a centre, which can sit outside the frame. The
   `Center X` / `Center Y` sliders do the same thing numerically.
4. Tune the shape under **Adjust** (調整). Each type shows its own sliders.
5. Add a layer with **+ Add layer** (＋ レイヤーを追加), then pick a type for
   it. Layers higher in the list draw in front. Up to eight layers.
6. Under **Size & color** (大きさ・色), set the image size and the layer's own
   colour, opacity and **White areas**. "White areas" chooses whether the holes
   inside a shape are cut out or filled white. Size presets are
   `16:9 (1920×1080)`, `Portrait 9:16`, `Square 2048`, `Social 4:5` and
   `B5 manuscript 350dpi` (2508×3541); width and height are editable, 64 to 8000
   px each.
7. Export under **Save** (保存): background transparent, white or black, and
   scale 1×, 2× or ½.
8. Load your own art with **Underlay…** (下敷き…) to line the centre up with a
   face or judge tone density. The underlay is never saved into the export.

### Inputs and parameters

Inputs are small. There is no project file to upload; a document is a share link
or the browser's own saved state.

| Language   | `?lang=` as `ja`, `en`, `zh-Hans`, `zh-Hant`, `ko`, `hi`, `th`, `es` or `fr` |

### Export and hand-off

- **PNG** — the flattened image at the chosen background and scale. The file
  name is `koukasen_<type>_<seed>.png`, built from the **selected** layer, so it
  changes when you select another layer. Scale 2× and ½ are exact multiples; the
  long edge is capped at 8000 px, and the app shows the real output size under
  "Export: W×H px" before you click.
- **SVG** — the same geometry as vector paths, always transparent, no
  background. Halftones and patterns become pattern fills; "white areas =
  transparent" cut-outs become masks. Name: `koukasen_<type>_<seed>.svg`.
- **ZIP by layer** — one PNG per visible layer, numbered `01_<type>_<seed>.png`
  upward, plus `all.png` and `all.svg`. Uncompressed ZIP, written by the app's
  own packer. Name: `koukasen_<type>_<seed>_layers.zip`.
- **Copy** — puts the PNG on the clipboard for a direct paste.

Hand-off:

- **CLIP STUDIO PAINT** — import the PNG. A transparent PNG stacks straight
  away. With a white background, set the layer blending mode to Multiply so the
  white drops out and only the lines remain. For SVG use File → Import → Vector.
- **Photoshop** — open or place the PNG on a layer above the art and set the
  blend mode to Multiply for a white-background file. The SVG imports as
  editable shape layers.
- **A web page** — use the SVG directly with `<img src="tone.svg">` or inline
  it. Both the halftone and the pattern tones stay sharp at any zoom, and the
  file is small: a 1920×1080 halftone layer exported at 10 KB in testing.
- **Web and 3D scenes** — the SVG also works as a CSS background behind a
  canvas, or as a texture on a plane in a [three.js](../3d/three-js.md) scene.
  The app has no three.js integration; this is a use of the file, not a feature.
- **Blender** — not published. The app documents only Clip Studio Paint and a
  paste into painting software and social media, so a Blender path is your own
  step: import the PNG as an image texture or as a reference plane.

### Driving it from an agent

Everything is reachable from Playwright with plain ids. This is the tested
recipe; it makes a focus-line layer, adds a halftone tone on top, and saves PNG,
SVG and ZIP.

```js
import { chromium } from 'playwright'
const APP = 'https://tools.oyasumi-gamedev.com/koukasen/'
const browser = await chromium.launch()
const page = await browser.newPage({ acceptDownloads: true })
await page.goto(APP + '?lang=en', { waitUntil: 'load' })
await page.waitForSelector('#cv')

// set a slider: write .value, then fire input AND change
const setParam = (k, v) =>
  page.$eval(
    `#paramCtl input[data-k="${k}"]`,
    (el, v) => {
      el.value = v
      el.dispatchEvent(new Event('input', { bubbles: true }))
      el.dispatchEvent(new Event('change', { bubbles: true }))
    },
    String(v)
  )

// 1. focus lines: fix the seed, then a few sliders
await page.$eval('#seed', (el) => {
  el.value = 'SMOKE1'
  el.dispatchEvent(new Event('change', { bubbles: true })) // change, not input
})
await page.click('#types .tbtn[data-t="focus"]')
for (const [k, v] of [
  ['n', 200],
  ['r0', 25],
  ['mura', 30]
])
  await setParam(k, v)

// 2. a halftone screentone layer on top of it
await page.click('#layerAdd')
await page.click('#types .tbtn[data-t="dots"]')
await setParam('pitch', 6)
await setParam('dens', 35)
await page.click('#paramCtl .chips button[data-v="round"]') // dot shape

// 3. background and size, then save
await page.click('#sizeChips button[data-v="2508x3541"]') // B5 350 dpi
await page.click('#exBg button[data-v="clear"]') // transparent
for (const [sel, tag] of [
  ['#dlPng', 'png'],
  ['#dlSvg', 'svg'],
  ['#dlZip', 'zip']
]) {
  const [dl] = await Promise.all([
    page.waitForEvent('download'),
    page.click(sel)
  ])
  await dl.saveAs(`out/${tag}_${dl.suggestedFilename()}`)
}
await page.screenshot({ path: 'out/screen.png' })
await browser.close()
```

Slider inputs are `<input type="range" id=... data-k="pitch">` inside
`#paramCtl`, so set `.value` then dispatch `input` and `change`. A chip choice
is `#paramCtl .chips button[data-v="round"]`. Type buttons are
`#types .tbtn[data-t="dots"]`. Size, export background and export scale are
`#sizeChips button[data-v="2508x3541"]`, `#exBg button[data-v="white"]` and
`#exScale button[data-v="2"]`.

**Hand-writable share link.** The share link is the only format an agent can
write without the app, and it is worth using: it sets the whole document in one
navigation. The hash is `#s=<payload>` where payload is one letter plus
base64url:

- `z` + base64url(raw DEFLATE) of the JSON state, or
- `j` + base64url(the JSON state) when compression is unavailable.

Only the diff from the defaults is written, but a full object also loads,
because every value is clamped and merged over the type defaults. Minimal
working example, checked by loading it and reading the state back:

```js
// node: build a share URL by hand
import { deflateRawSync } from 'node:zlib'
const state = {
  v: 1,
  W: 1200,
  H: 1600,
  ex: { bg: 'white', scale: 1 },
  layers: [
    {
      t: 'speed',
      s: 'HAND-1',
      p: { ang: 90, n: 300, len: 40, band: 40 },
      on: 1,
      c: '#d7263d',
      o: 80,
      x: 1
    },
    {
      t: 'dots',
      s: 'HAND-2',
      p: { pitch: 4, dens: 60 },
      on: 1,
      c: '#000000',
      o: 100,
      x: 0
    }
  ]
}
const b64u = (b) =>
  Buffer.from(b)
    .toString('base64')
    .replace(/\+/g, '-')
    .replace(/\//g, '_')
    .replace(/=+$/, '')
const hash =
  'z' + b64u(deflateRawSync(Buffer.from(JSON.stringify(state), 'utf8')))
// open: https://tools.oyasumi-gamedev.com/koukasen/?lang=en#s=<hash>
```

Keys: `v` version (1), `W`/`H` canvas px, `ex`
`{bg: clear|white|black, scale: 0.5|1|2}`, `layers[]` with `t` type id, `s`
seed, `p` params, `on` 1/0, `c` hex colour, `o` opacity 5–100, `x` 1 = cut white
areas out. Type ids are the `data-t` values used above: `focus`, `rays`,
`betaflash`, `uniflash`, `speed`, `curve`, `wind`, `fall`, `rain`, `kakeami`,
`kakegrad`, `kakebeta`, `nawaami`, `nawagradation`, `nawaradial`, `dots`,
`lines`, `grad`, `pattern`, `stipple`, `sand`, `sparkle`, `flowers`, `hearts`,
`petals`, `bubbles`, `snow`.

## When to use it

- Use it for manga and comic backgrounds: focus lines for a reveal, speed lines
  for a run, drop lines for a shock beat, cross-hatch and rope hatch for shadow,
  night or unease, halftone and line tone for clothing and flat greys.
- Use it when the result has to stay vector. The SVG export is real paths and
  pattern fills, so it scales to a poster or an animation without pixel loss.
- Use it for non-comic design work where a halftone or a speed line is the
  motif: a hero background for a web page, a poster, a zine cover, a social
  graphic, a skate or music brand texture.
- Use it for 3D and web scenes as a cheap texture source: the SVG is light
  enough to use inline as a CSS background, or as a texture on a plane in a
  [three.js](../3d/three-js.md) scene.
- Use it when an agent has to produce the asset headlessly. The share hash plus
  `#dlPng` and `#dlSvg` is a complete, scriptable pipeline.
- Skip it when you need a single seamless texture tile rather than a full-frame
  composition, and try [Tabbied](../utilities/tabbied.md) or
  [Fffuel](../utilities/fffuel.md) instead.
- Skip it when you want a dithered or retro-print treatment of an existing
  photo, which is [Dither Lab](../utilities/dither-lab.md) or
  [DotForge](../utilities/dotforge.md).
- Skip it when the tone has to live inside a real drawing tool with blend modes
  and masks you will keep editing; build the tone in
  [Penpot](../interface-design/penpot.md) or Clip Studio Paint material layers.
- Skip it when the deliverable is a whole page: take the layout from
  [Manga Panel Layout Generator](../comics/komawari.md), the balloons from
  [Speech Bubble Generator](../comics/fukidashi.md) and the character from
  [Name Gacha](../comics/namegacha.md), and add the effects here last.

## Agent notes

- App URL: <https://tools.oyasumi-gamedev.com/koukasen/>. Add `?lang=en` for
  English. The app writes the chosen language to `localStorage`
  (`koukasen.lang.v1`) and saves the document to `koukasen_state_v1`.
- URL parameters: `?lang=<code>` (9 codes listed above), `?embed=1` (activates
  the embed UI, only inside an iframe), `?host=comicalizer` (embed heading). The
  share hash is `#s=<z|j><base64url>`.
- The app **strips the hash** from the address bar with `history.replaceState`
  after loading, so read the state from `localStorage` rather than from
  `location.hash` after load.
- A hash-only navigation does not re-run `init()`. Navigate to `about:blank`
  first, or call `page.reload()`, when you load a second share link in one page.
- Key selectors: `#cv` (preview canvas), `#vp` (stage),
  `#types .tbtn[data-t=…]`, `#paramCtl input[data-k=…]`,
  `#paramCtl .chips button[data-v=…]`, `#seed`, `#layerAdd`, `#layerList`,
  `#sizeChips button[data-v=…]`, `#szW`, `#szH`, `#exBg button[data-v=…]`,
  `#exScale button[data-v=…]`, `#dlPng`, `#dlSvg`, `#dlZip`, `#cpPng`, `#qPng`,
  `#shareCopy`, `#langSel`, `#underFile`.
- Limits: canvas 64–8000 px per side. Export long edge capped at 8000 px; a 2×
  export of B5 (2508×3541) gives 5016×7082. Maximum 8 layers. Seed trimmed to 24
  characters. Share-link input cap 16000 characters, decompressed state cap 1
  MiB, generated share URL refused above 8000 characters. iOS Safari refuses PNG
  blobs over roughly 16.78 Mpx; the app reports "toobig" instead of a blank
  file.
- Performance: any render that takes over 150 ms is deferred until you stop
  moving, with a timeout of up to about 400 ms. Stacked rope hatch at B5 is the
  heavy case. Allow a second or two after a change before you screenshot or read
  pixels. Turn on `#prevFine` only when you need it.
- Beta status: not labelled beta. The tool is dated in the source; the French
  translation landed 2026-10-13 and Thai and Spanish on 2026-10-09.
- Licence and attribution: output is free for commercial and non-commercial use
  with no credit required. The **source code** has no published licence, and the
  site disclaimer reserves copyright, so do not copy the app code.
- What never leaves the browser: the document, the underlay image and every
  export. The only network call is the contact form. Pressing Send attaches the
  tool name and UI language to the message.
- Cross-tool hand-off: in `?embed=1` mode inside
  [Name Gacha](../comics/namegacha.md) or
  [Comicalizer](../comics/comicalizer.md), the app posts the visible layers to
  the parent frame with `postMessage` as
  `{app:'koukasen', type:'pick', st:{W, H, layers}, to, upd}`. Only
  `window.parent` can talk to it; it refuses any other source.
- Gotchas hit in testing: dispatch `change` on `#seed` (not `input`); the type
  buttons apply to the selected layer, so add a layer before picking a second
  type; `#dlPng` and `#qPng` do the same save, so use one to avoid two
  downloads; the B5 chip writes 2508×3541, not a rounded number; the export file
  name comes from the selected layer, not the front layer.

## Alternatives in this repo

- [Tabbied](../utilities/tabbied.md) — generative geometric patterns as SVG, for
  seamless tiles rather than a composed frame.
- [Fffuel](../utilities/fffuel.md) — generative SVG textures and gradients, a
  broader toolbox with less manga-specific control.
- [Dither Lab](../utilities/dither-lab.md) — dithering filters applied to a
  photo, the raster counterpart to a halftone screentone.
- [SVGOMG](../utilities/svgomg.md) — squashes the exported SVG; note that
  dropping the pattern `<defs>` will break a halftone fill.
