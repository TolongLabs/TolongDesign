## What it is

GetLayers packages finished visual treatments as prompts or downloadable source
so an AI coding assistant can build a page from a more specific visual starting
point. Categories include sections, templates, backgrounds, and 3D scenes.

The documented workflow is to copy a prompt into the AI tool already in use,
generate a standalone HTML starting point, and ask the model to adapt it to the
project's framework. Full Stack adds source files and an MCP connection to the
library.

Free prompts are described as a curated set for browsing and experimenting. Docs
describe Unlimited as adding commercial-use prompts, but the Terms page says
plans carry personal-use licences. This conflict needs resolution before client
delivery.

## Paywall and pricing

- **Free:** A curated prompt set is publicly available for experimentation.

## How to use

1. Browse the layer library and choose a visual foundation that fits the
   product's audience and brand.

2. Copy the prompt into the coding assistant with project context. Ask it to
   adapt the result to the existing framework, content, and design tokens.

3. For a closer match, Full Stack subscribers can download source files or
   connect the GetLayers MCP server.

4. Treat the first result as a starting point: replace demo content, rework the
   composition, and check performance and accessibility.

## When to use it

- Use it when an AI-generated page needs stronger visual direction than a
  general prompt usually provides.
- Skip it when you need a documented code licence, exact repeatable components,
  or production source on the free tier; use
  [UI Layouts](../component-libraries/ui-layouts.md) or
  [Tailark](../component-libraries/tailark.md).
