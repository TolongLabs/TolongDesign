## What it is

Bencho is an interactive site for exploring interface blocks and micro-
interactions with adjustable physics. Its home page presents demos such as asset
swapping, image comparison, and slide-to-confirm.

The site also links to adjacent collections such as sounds, curated interface
finds, and an infinite canvas. Those are useful for exploration but do not
establish that the demos are a reusable code package.

The checked pages did not publish an install command, source code, licence, or
pricing plan. Treat Bencho as a live reference and prototype surface.

## How to use

1. Open a demo on the home page and interact with its controls to see the
   response and motion.
2. Try different input values or pointer interactions where exposed, and capture
   the behavior that matters to the intended project.
3. Write a short implementation brief covering trigger, response, bounds,
   reduced-motion fallback, and mobile behavior; implement that behavior in the
   project stack.

No published install command or code snippet could be verified. Use the public
site as a reference only until the publisher documents a current implementation.
