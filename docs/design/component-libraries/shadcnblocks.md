## What it is

shadcnblocks is a large catalogue of website and application blocks built around
shadcn/ui conventions. Its component pages cover common marketing and product
sections.

The checked catalogue reported more than 2,157 free and premium components. The
service also offers templates and an administrative kit.

A CLI registry can add supported blocks to a project. The free and paid entries
are mixed in the catalogue, so check the selected block and licence before using
it.

## Paywall and pricing

- **Free:** The catalogue includes free blocks alongside gated premium blocks.
- **Paid:** Pro is $149 one-time, Premium $299 one-time, and Elite $399 one-time
  on the checked pricing page. Individual templates and kits may have separate
  prices.
- **Sign-up required?** Yes — an account is needed for purchased content and
  tools; public component pages are browseable.
- **Licence for client work:** The site offers commercial use under its plan
  licence but prohibits redistribution or resale of the source assets.

Pricing and access were checked on 2026-10-07.

## How to use

1. Browse the component catalogue or templates and identify blocks that match
   the page structure.
2. Use the documented shadcn CLI command to add an available block.
3. Review the copied source, replace sample content, and check the applicable
   commercial licence for paid blocks or templates.

Install or add the documented component with:

```bash
npx shadcn@latest add @shadcnblocks/hero1
```

The official docs show this minimal usage or setup:

```bash
npx shadcn@latest add @shadcnblocks/hero1
```

## When to use it

- Use it when a project uses shadcn/ui and needs prebuilt marketing sections or
  page structures quickly.

- Skip it when the project needs a permissive open-source component library;
  compare [blocks.so](../component-libraries/blocks-so.md) or
  [daisyUI](../component-libraries/daisyui.md).

## Agent notes

- Run the CLI command for the exact block identifier shown in the catalogue.
- The catalogue mixes free and paid items; verify access and plan terms before
  committing a paid block.
- Paid assets cannot be redistributed as a standalone library or template under
  the published terms.
