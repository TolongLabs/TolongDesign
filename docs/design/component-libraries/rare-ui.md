## What it is

Rare UI is a collection of animated React components distributed through a
shadcn-compatible registry. The site highlights unusual motion and interaction
treatments.

The home page described more than 22 components, with one file per component and
support for CLI and MCP workflows. Examples include letter effects, task lists,
and step indicators.

The repository licence adds a Commons Clause restriction and attribution
requirement to MIT-style terms. The components are free, but they cannot be
treated as unrestricted MIT assets.

## Paywall and pricing

- **Free:** The published component registry is free to browse and install.
- **Paid:** Optional sponsorship tiers listed in the terms are Silver
  $100/month, Gold $150/month, and Diamond $250/month. Sponsorship is not
  required to use the components.
- **Sign-up required?** No — public components are available without an account;
  optional sponsorship is separate.
- **Licence for client work:** The custom terms require visible credit and
  restrict selling, sublicensing, or redistributing the components. Check the
  full terms before client delivery.

Pricing and access were checked on 2026-10-07.

## How to use

1. Choose a component page and check its preview, props, and licence
   requirements.
2. Add the component with the documented shadcn command or use the published MCP
   workflow.
3. Keep the required visible Rare UI credit in the shipped interface and avoid
   redistributing the component source as a standalone product.

Install or add the documented component with:

```bash
npx shadcn@latest add swamimalode07/rare-ui/fluid-orb
```

The official docs show this minimal usage or setup:

```bash
npx shadcn@latest add swamimalode07/rare-ui/fluid-orb
```

## When to use it

- Use it when a React page needs a distinctive animation and the project can
  retain the required attribution.

- Skip it when attribution cannot fit the product or the component must be
  redistributed; compare
  [Fancy Components](../component-libraries/fancy-components.md) or
  [Amicro](../component-libraries/amicro.md).

## Agent notes

- The custom licence requires visible credit and limits resale, sublicensing,
  and redistribution.
- The site documents a CLI and MCP; use component-specific registry identifiers.
- Reduced-motion behavior is a stated consideration in the project; preserve it
  when customizing animations.
