## What it is

23rd is a shadcn-compatible registry of expressive components, shaders,
backgrounds, logos, and page effects. Its docs provide live previews and
per-item install instructions.

Components are available for React and Svelte 5. The code is installed into the
project, so teams can edit source rather than depend on a hosted renderer.

The project describes itself as open source, but the repository pages reviewed
did not expose an SPDX licence file. Treat the licence as unknown until
confirmed from the repository or item metadata.

## How to use

1. Start from a shadcn project and pick the React or Svelte 5 install variant on
   the component page.

2. Install the registry item using the displayed command. The shader-gradient
   page provides an exact React example.

3. Place a shader or background inside a relatively positioned, isolated
   container, with product content in a higher stacking context.

4. Tune documented props and verify contrast, performance, and motion behavior
   against real page content.

Official setup or install command:

```bash
pnpm dlx shadcn@latest add @23rd/shader-gradient
```

Minimal documented usage or configuration example:

```tsx
'use client'

import { ShaderGradient } from '@/components/ui/shader-gradient'

export function Hero() {
  return (
    <section className="relative isolate min-h-svh overflow-hidden">
      <ShaderGradient />
      <div className="relative z-10 p-10">Your content</div>
    </section>
  )
}
```

## When to use it

- Use it when a page needs an expressive shader, interactive wordmark, unusual
  footer, or another distinctive visual moment.
- Skip it when an effect would compete with content or a restrained component
  set is needed; compare [shadcn/ui](../component-libraries/shadcn-ui.md).

## Agent notes
