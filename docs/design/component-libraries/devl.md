## What it is

devl is a personal scratch pad of interface experiments by Sean Brydon. The site
says it contains 158 designs built on coss-ui, with raw CSS, shaders, SVGs, and
canvas work mixed in. Categories include layouts, forms, auth, dashboards,
tables, settings, and charts.

This is a gallery, not a maintained component package or production starter. The
GitHub repository says the designs are proofs of concept and that the showcase
has no backend, authentication, or database. The site provides a keyboard-driven
browser and lets visitors inspect code.

The repository is public, but no licence was identified on the repository page
checked. Do not assume public source means permission to reuse it in a
commercial client project.

## How to use

1. Browse category lists on the homepage or press Command-K to jump to an
   experiment.
2. Open a design, then use the page controls to move between examples, change
   theme, or reveal code.
3. Record the composition, density, navigation, and one interaction at a time.
4. Turn the findings into a TolongLabs brief: describe the page structure,
   content hierarchy, responsive behavior, and motion separately. Rebuild the
   approved pattern in the project's own design system.

## When to use it

- Use it when a product needs fresh app-shell, settings, empty-state, or
  dashboard directions.
- Use it when a developer wants to study a compact layout before drafting a
  design brief.
- Skip it as a drop-in component dependency; use a licensed library such as
  [Ruru UI](../component-libraries/ruru-ui.md) for reusable primitives.

## Agent notes

There is no supported package install. The site advertises Command-K search and
a code-view shortcut on examples. Treat the code as inspiration until a reuse
licence is confirmed. The linked coss-ui foundation is separate from devl's own
experiments and has its own terms.
