## What it is

Shadcn Studio is a collection of shadcn/ui components, blocks, full pages,
templates, illustrations, and theme tools. It also offers a drag-and-drop
builder, a theme generator, a Figma UI kit, an IDE extension, and an MCP server.

The free Community tier exposes a limited set of components and code. Paid plans
add access to broader libraries and product features. Its collection and service
are separate from the open-source shadcn/ui project.

The pricing page currently shows one-time plan prices. Elsewhere on that page,
copy also refers to a $249 lifetime offer. Confirm the current checkout and
included products before purchase because the page presents different
price/offer information in separate sections.

## Paywall and pricing

- **Free:** Community is listed as free forever with limited blocks, pages,
  templates, components, illustrations, and feature access.
- **Paid:** Basic $99, Pro $199, Team $449, and Enterprise $849, each shown as a
  one-time payment. Team lists 15 seats; Enterprise lists unlimited seats.
- **Sign-up required?** An account is used to access the workspace and save
  items.
- **Licence for client work:** the pricing table includes commercial usage with
  paid plans; inspect the linked licence for exact restrictions.
- **Checked:** 2026-10-07.

## How to use

1. Browse components, blocks, or templates and preview the layout in the
   browser.
2. Use the builder or theme tools to establish a visual direction, then select a
   component or block for the target stack.
3. Copy the shadcn CLI command supplied by that selected item into the project.
   There is no universal install command for the whole catalogue.
4. For agent use, follow the official MCP or IDE-extension setup and grant the
   tool access only to the project context it needs.
5. Review generated code, commercial terms, and dependencies before merging.

Each selected block has its own files and code. Use the selected item's Code tab
or shadcn CLI command rather than reusing a generic import path.

## When to use it

- Use it when a project needs a wide range of shadcn-ready page sections.
- Use it when a visual builder or MCP workflow helps the team move from
  reference to editable source.
- Skip it when a project needs a single uniform open-source licence or when the
  paid collection is outside budget.

## Agent notes

The product documents an MCP server and IDE extension. Registry commands vary by
selected item; copy the command from its component page instead of inventing a
package name. Some plans include commercial usage, but agents should link the
chosen asset to the official licence terms and preserve any required
attribution.
