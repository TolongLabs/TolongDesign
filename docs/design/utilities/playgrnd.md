## What it is

Playgrnd (playgrnd.tools) is a curated collection of more than 50
single-purpose, browser-based generative art and visual design tools. Built
around the ethos of lightweight, offline-first web software, every tool runs
completely in the browser with zero network calls, no file uploads, and no
server-side storage.

The tools are grouped into categories covering Backgrounds, Patterns, Textures,
Posters, and Badges:

- **Backgrounds:** `Terrain` (layered contour landscapes), `Filament` (flowing
  thread fields), `Aura` (soft vibrant gradients), `Prism` (pixel aurora
  backdrops), and `Sonar` (dithered topographic landmasses).
- **Patterns:** `Oddgrid` (generative pixel compositions), `Zig` (rounded zigzag
  patterns), `Quilt` (pixel blanket designs), `Warp` (op-art optical patterns),
  and `Relief` (isometric block lattices).
- **Textures & Posters:** `Stipple` (halftone dot portraits of light), `Atlas`
  (text-mode terrain maps), `Static` (glitch pixel posters), and `Riso` (torn
  paper collage layouts).

Each tool features keyboard shortcuts, randomize buttons, seed generators, and
direct export options, producing crisp graphic assets ready for web layouts.

## How to use

1. Visit [playgrnd.tools](https://www.playgrnd.tools/) in your browser.
2. Filter the index by category (e.g., Backgrounds, Patterns, or Textures).
3. Click a tool or use keyboard navigation (type to filter, press Enter to
   open).
4. In the tool canvas, tweak visual parameters (density, palette, frequency,
   stroke weight) or tap the Spacebar to re-roll random seeds.
5. Export your artwork as a high-resolution PNG or SVG vector file.
6. Use the asset as an atmospheric website backdrop or feature banner:

```html
<section class="relative min-h-[400px] overflow-hidden bg-neutral-900">
  <img
    src="/assets/terrain-backdrop.png"
    alt="Generative contour background"
    class="absolute inset-0 h-full w-full object-cover opacity-40 mix-blend-screen"
  />
  <div class="relative z-10 p-12 text-white">
    <h2 class="text-3xl font-bold">Spatial Intelligence</h2>
  </div>
</section>
```

## When to use it

- Use it when designing distinctive, art-directed landing pages that require
  organic visual texture rather than generic corporate stock photos.
- Use it to create eye-catching blog post banners, podcast cover art, or event
  posters.
- Skip it if you need standard SVG noise filters or SVG blobs; use
  [fffuel](../utilities/fffuel.md) instead.
- Skip it if you need real-time dither video effects; use
  [DotForge](../utilities/dotforge.md) instead.
