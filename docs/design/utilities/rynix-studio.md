## What it is

Rynix Studio is listed as a playground for real-time video visual effects. The
official edit URL did not load in this research view. The linked public
repository describes a browser-based creative tool for images, video, and webcam
input, with more than 30 effects, including halftone, ASCII, dithering, and dot
grids.

The repository says processing happens on the device and can work offline.
However, the live editor and its current effect list could not be inspected, and
the repository did not publish a licence file in the pages reviewed. Treat those
repository details as project claims rather than a confirmed current deployment.

## How to use

The current control layout could not be verified. If the editor is available in
a browser:

1. Open the studio and select an image, video, or webcam source supported by the
   current interface.
2. Try one effect at a time, starting with a low-intensity treatment so the
   source composition remains readable.
3. Compare the live result at the final display size and check motion effects
   with reduced-motion expectations.
4. Confirm export format, processing location, and licence terms before using
   the output in a production project.

These are evaluation steps, not confirmed button-by-button instructions.
