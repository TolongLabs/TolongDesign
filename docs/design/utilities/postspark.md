## What it is

PostSpark is a browser editor for presenting product screenshots on styled
backgrounds. Its pages offer separate workflows for screenshots, X posts, device
mockups, and GitHub contribution visuals. A template library provides starting
compositions that can be personalized before export.

The official page advertises image export without a watermark or account for at
least the Android device mockup workflow. Pro adds video and animated exports
and higher-resolution output. This makes PostSpark useful for quick campaign
graphics, while keeping final typography and layout review in the hands of the
project designer.

## How to use

1. Choose the workflow that matches the deliverable: a screenshot, X post,
   device mockup, or GitHub contribution graphic.
2. Upload the product image or screenshot and select a template or background.
3. Adjust the crop, spacing, device frame, and surrounding color so the app
   remains the focal point at the intended social size.
4. Add concise copy only when it improves context; check that it remains legible
   in the platform's feed preview.
5. Export a still image using the free flow. Use Pro only if the campaign needs
   the advertised video, animation, or higher-resolution output.

For a TolongLabs project, use the editor as a presentation layer. Keep the
canonical product screenshot and its source file in the project itself.

## When to use it

- Use it when a product team needs a quick series of consistent social images
  from existing screenshots.
- Use the mockup flow when a device frame adds useful context to a release
  announcement.
- Skip it when the design requires precise brand typography, layered editing, or
  repeatable generation inside a build pipeline. Use project-owned design files
  or code instead.
