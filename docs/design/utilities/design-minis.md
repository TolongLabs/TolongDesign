## What it is

Design Minis (designminis.com) is an independently curated directory created by
designer Kostiantyn Motresku that tracks the proliferation of specialized,
single-purpose design web utilities. Rather than monolithic design suites, web
design engineers increasingly build and rely on small, focused tools that
execute one specific task exceptionally well.

The platform indexes over 138 micro-tools organized across distinct workflow
facets:

- **Motion & Easing:** CSS cubic-bezier editors, easing visualizers, GIF makers,
  and keyframe curve generators.
- **Color & Accessibility:** Contrast checkers, gradient generators, color
  palette builders, and tone balance calculators.
- **Typography & Layout:** Type scales, fluid clamp calculators, font pairing
  sandboxes, and corner radii tools.
- **Effects & Shaders:** Real-time dither studios, liquid orb editors, glitch
  generators, and noise textures.

The directory serves as a living bookmark collection for designers and
developers seeking high-utility web tools without wading through SEO spam or
subscription traps.

## Paywall and pricing

- **Free:** Browsing the entire collection of 138+ tools, filtering by category,
  and submitting new utilities to the directory are 100% free.
- **Paid:** None for tool access. Monetization is handled through optional
  sponsor banner placements for external products.
- **Sign-up required?** No. No account or registration is required to browse or
  access listed tools.
- **Licence for client work:** Directory of external web utilities. Each
  individual linked tool operates under its own licensing terms (most of which
  are free or freemium web utilities).

## How to use

1. Go to [designminis.com](https://www.designminis.com/) when encountering a
   specific design or front-end math hurdle.
2. Filter by domain: Motion, Color, Typography, Layout, SVG, 3D, or Effects.
3. Toggle the pricing filter (Free / Freemium) if seeking entirely free
   utilities.
4. Click through to open the targeted single-purpose tool in a new tab.
5. Generate the desired CSS snippet, scale tokens, or SVG path.
6. Incorporate the resulting tokens or easing curves into your project's design
   system:

```css
/* Custom CSS easing curves sourced from tools on Design Minis */
:root {
  --ease-spring: cubic-bezier(0.175, 0.885, 0.32, 1.275);
  --ease-smooth: cubic-bezier(0.16, 1, 0.3, 1);
  --shadow-elevation-1: 0 1px 2px 0 rgb(0 0 0 / 0.05);
  --shadow-elevation-2:
    0 4px 6px -1px rgb(0 0 0 / 0.1), 0 2px 4px -2px rgb(0 0 0 / 0.1);
}
```

## When to use it

- Use it when solving a specific mathematical or visual calibration problem
  (e.g. generating smooth shadow curves, fluid type clamps, or cubic Béziers).
- Use it to discover emerging, independent developer tools not listed on major
  software directories.
- Skip it if you need an end-to-end component library; use
  [docs/README.md](../../README.md) or the TolongDesign catalogue instead.
- Skip it if you need vector asset conversion; use
  [Transform](../utilities/transform.md) or [SVGOMG](../utilities/svgomg.md)
  directly.
