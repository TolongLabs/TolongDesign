## What it is

ASCII is a single-page artboard for making images out of characters. The page
supports text, uploaded images, and generated scenes such as a donut, cube,
matrix, plasma, fire, and tunnel.

Controls include character sets, palettes, cell size, contrast, motion speed,
and named visual looks. The page says images stay on the device and the latest
project autosaves in the current browser.

The tool can export text, ANSI, PNG, GIF, video, and a project file. The site
does not publish a separate template gallery or a component package.

## How to use

1. Open the editor and choose an artboard size or keep the default 1200 × 800.
2. Choose **text**, **image**, or **generate** mode. For an image, upload or
   paste a source image; the page says processing stays on the device.
3. Pick a character set and palette, then adjust cell size and contrast until
   the subject reads at the intended display size.
4. For motion, choose one of the listed engines and tune its speed. Pause the
   animation before exporting a still.
5. Use the export control to download PNG, GIF, video, text, ANSI, or a project
   file. Save a project file when you need to continue on another browser.

- [Animated character scenes](https://ascii.krackeddevs.com/) — try listed

## When to use it

- Use it for a quick ASCII treatment, an experimental hero accent, or a
  downloadable image that does not need to stay editable in the website.
- Skip it when the project needs an accessible, responsive live text treatment
  or a stable code API; implement that deliberately in the site instead.
