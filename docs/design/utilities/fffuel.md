## What it is

Fffuel is a comprehensive suite of more than 50 single-purpose SVG generators,
color utilities, and design tools created for web developers and designers.
Rather than providing static asset packs, each tool provides an interactive
browser playground parameterized by sliders, seeds, and color pickers.

The generators span an enormous range of decorative website graphics:

- **Noise & Gradients:** `nnnoise` (SVG noise texture generator), `ffflux`
  (fluid SVG gradients), `gggrain` (grainy gradients), and `bbblurry` (blurry
  background mesh shapes).
- **Geometric Patterns:** `rrrepeat` (repeating SVG shapes), `ooorganize` (grid
  patterns), `mmmotif` (isometric pattern builder), and `sssurf` (layered wave
  dividers).
- **Shapes & Blobs:** `ssshape` (organic SVG blob generator), `llline` (wavy
  lines), `ccchaos` (wild wavy shapes), and `pppointed` (custom SVG arrow
  heads).

All generators output clean, resolution-independent SVG markup or CSS code that
can be copied in one click, downloaded as vector files, or imported directly
into Figma.

## How to use

1. Browse the tool index at [fffuel.co](https://fffuel.co/).
2. Select the generator for your desired graphic (e.g. `nnnoise` for texture or
   `ffflux` for fluid gradients).
3. Tune sliders for frequency, octaves, blur, color stops, and randomize seed.
4. Click "Copy SVG" or "Copy CSS".
5. Paste into your stylesheet or component to style a hero background:

```html
<section class="relative overflow-hidden bg-neutral-950 py-24 text-white">
  <!-- Inline SVG noise filter generated by nnnoise -->
  <svg
    class="pointer-events-none absolute inset-0 h-full w-full opacity-20"
    xmlns="http://www.w3.org/2000/svg"
  >
    <filter id="noiseFilter">
      <feTurbulence
        type="fractalNoise"
        baseFrequency="0.65"
        numOctaves="3"
        stitchTiles="stitch"
      />
    </filter>
    <rect width="100%" height="100%" filter="url(#noiseFilter)" />
  </svg>

  <div class="relative mx-auto max-w-5xl px-6">
    <h1 class="text-4xl font-bold">Engineered for Reliability</h1>
  </div>
</section>
```

## When to use it

- Use it when crafting visual backdrops, hero sections, card gradients, or
  subtle grain overlays for modern landing pages.
- Use it to create dynamic SVG section dividers and curved shapes without
  drawing vectors manually in Illustrator.
- Skip it if you need complete multi-tool offline art generation; use
  [Playgrnd](../utilities/playgrnd.md) instead.
- Skip it if you need to optimize existing SVG assets; use
  [SVGOMG](../utilities/svgomg.md) instead.
