## What it is

UX Archive is a specialized design reference platform dedicated to cataloguing
mobile user experience journeys and interaction sequences. Co-founded by Arthur
Bodolec (co-founder of Feedly) and Chris Polk, the platform was established to
help product designers compare how popular mobile applications solve specific
user experience problems.

Unlike galleries that catalog isolated screens or static marketing homepages, UX
Archive organizes its library around discrete user tasks and workflows. Instead
of browsing simply by application name, users browse by flow types such as
onboarding, sign-up, checkout, search, permissions requests, and account
deletion.

Each journey is documented as a linear sequence of high-resolution mobile
screens, allowing teams to observe the exact micro-copy, modal dialogs, input
fields, and progress indicators presented to users at each touchpoint. This
provides historical and comparative context for optimizing mobile product
funnels.

## Paywall and pricing

- **Free:** Public pattern browsing, searching task categories, access to public
  profile capabilities, and saving up to 3 private patterns.
- **Paid:** Plus Plan is $7/month, offering unlimited private patterns, original
  quality screenshot downloads, and workspace pattern forking. Pro Plan is
  $12/month, adding team collaboration workspaces and advanced analytics.
- **Sign-up required?** Browsing public workflows does not require an account.
  Creating a free account is required to save collections, fork patterns, or
  subscribe to paid tiers.
- **Licence for client work:** Screen sequences document proprietary mobile
  interfaces copyrighted by their respective app makers. They serve as
  comparative design references and UX research material.

## How to use

1. Select target user task: Navigate to specific workflow categories (such as
   Onboarding, Sign-up, or Profile Creation) depending on the feature being
   scoped for TolongLabs clients.
2. Compare competing implementations: Review side-by-side flow progressions from
   prominent mobile apps (e.g., Duolingo, Airbnb, Spotify) to analyze step
   counts and friction points.
3. Map funnel steps: Note key architectural decisions—such as progressive
   profiling, social sign-in placements, and permission priming screens.
4. Draft wireflow specifications: Incorporate documented flow steps and copy
   strategies directly into product requirements and UX wireframes.

## When to use it

- Use it when designing mobile onboarding sequences, authentication funnels, or
  multi-step verification flows.
- Use it to study progressive disclosure patterns and friction reduction in
  mobile applications.
- Skip it when designing desktop SaaS marketing landing pages or marketing
  websites; choose [Landingfolio](../design-galleries/landingfolio.md) or
  [Lapa Ninja](../design-galleries/lapa-ninja.md) instead.

## Agent notes

- Visual UX archive without an API or programmatic access endpoints.
- Agents should guide human developers toward specific task URLs when
  researching interaction design decisions for mobile app specifications.
- Assets are proprietary mobile application screenshots; do not duplicate
  branded UI elements directly into production code.
