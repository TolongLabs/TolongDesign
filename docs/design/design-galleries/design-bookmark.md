## What it is

Design Bookmark is a directory of design tools, websites and resources grouped
into broad categories such as Design, AI, Development, No-Code and Web,
Marketing, Productivity, Business and Learning.

Visitors can search, browse categories and sort listings. Google sign-in
supports bookmarking and sync. The listed resources have their own products and
terms, so the directory’s label should not substitute for checking the source.

## Paywall and pricing

- Free: The directory is publicly browsable; bookmarking and sync use Google
  sign-in.
- Paid: No paid reader tier was published. Sponsorship options are for listing
  visibility.
- Sign-up required? No to browse; yes to sync bookmarks.
- Licence for client work: Each linked resource sets its own licence and
  commercial terms.

The access and pricing details above were checked on 2026-10-07.

## How to use

1. Search by a task or browse one of the resource categories.
2. Sort the results by newest or A–Z when you need a narrower scan.
3. Open the resource entry and follow its official link to check features and
   cost.
4. Use the bookmark action if you want saved listings synced to an account.
5. Shortlist tools by project constraints, not only by directory tags.

**Capture in a TolongLabs design brief:**

- Capture the resource name, category and official destination.
- Confirm licence, pricing and framework support on the destination site.
- Note whether a bookmark is only an idea or an approved project dependency.

## Examples

- [OpenCapture](https://designbookmark.com/tool/opencapture) A freemium browser
  capture tool for full-page screenshots, annotation and redaction.
- [Wall of Portfolios](https://designbookmark.com/tool/wall-of-portfolios) A
  directory entry for UX, UI and product-design portfolios.
- [OG Image Design](https://designbookmark.com/tool/og-image-design) A resource
  for OG-image examples and URL preview validation.

## When to use it

- Use it when you need a broad directory and want a simple way to keep a
  personal shortlist.
- Skip it when a specialist category directory offers better filtering or
  verified technical detail.

## Agent notes

The directory is not an API or package registry. No public machine-readable
integration was found in the checked pages.

Sign-in is for bookmark syncing; do not assume it is needed to view the listed
resources.
