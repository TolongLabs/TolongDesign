## What it is

Screenlane originated as a popular design curation platform (initially launched
under the name UI Movement by founder Ramy Khuffash) dedicated to indexing real
interface screens across web and mobile applications. In July 2024, Screenlane
merged with Page Collective and rebranded under the Page Flows banner. The
original `screenlane.com` domain now automatically redirects to `pageflows.com`.

Following this evolution, the platform shifted focus from purely static screen
captures to comprehensive, annotated video recordings of real user flows.
Instead of viewing single isolated screens out of context, subscribers observe
complete interaction journeys from start to finish—including account creation,
settings updates, payment checkouts, and upgrade prompts.

The repository indexes hundreds of top web and mobile applications, providing UX
designers and product engineers with clear documentation of how high-growth
products handle transition timing, validation states, micro-interactions, and
system notifications.

## Paywall and pricing

- **Free:** Limited preview excerpts and screenshots of select featured user
  flows on the public homepage.
- **Paid:** Full access requires a paid membership. A 3-day trial is available
  for $2.95 (non-refundable). Ongoing plans are billed at $39/quarter
  (equivalent to $13/month) or $99/year ($8.25/month). Team accounts are
  available at $199/year covering multiple seats.
- **Sign-up required?** Yes. Browsing the full recording archive and viewing
  complete screen flows requires an active paid account.
- **Licence for client work:** Recordings document live, third-party proprietary
  products for educational and research purposes. Flows and assets cannot be
  repackaged; they serve strictly as UX benchmarks.

Verified on the official Page Flows pricing page on 2026-10-07.

## How to use

1. Select platform and interaction objective: Navigate to web or mobile flow
   directories to inspect specific tasks (e.g., inviting a team member or
   upgrading to an enterprise plan).
2. Deconstruct the interaction sequence: Watch the screen recording to observe
   animation timing, confirmation dialogs, modal handling, and empty states.
3. Note error and edge cases: Observe how top apps communicate form errors,
   async loading spinners, and progressive field disclosure.
4. Translate insights into PRDs: Reference specific flow recordings when writing
   product requirement documents or briefing frontend engineers on multi-step
   interaction logic.

## When to use it

- Use it when designing multi-step transactional flows, billing upgrades, team
  invitation systems, or complex SaaS onboarding journeys.
- Use it to study dynamic transitions and micro-copy in motion rather than
  relying solely on static screenshots.
- Skip it when seeking free inspiration without a paid subscription; consult
  [UX Archive](../design-galleries/ux-archive.md) or
  [Pttrns](../design-galleries/pttrns.md) instead.

## Agent notes

- Not agent-friendly: Requires authenticated paid session cookies, and content
  is primarily hosted as streaming video recordings.
- Domain note: `screenlane.com` issues an HTTP 301 redirect to `pageflows.com`.
  Always target `pageflows.com` URLs in documentation.
- Coding agents can point developers to specific Page Flows category URLs for
  human UX analysis during feature planning.
