## What it is

One Page Love is the web's leading gallery dedicated exclusively to single-page
websites, landing pages, and one-page templates. Founded in 2008 by South
African designer and maker Rob Hope (now published with Some Studio), the
platform has catalogued over 9,000 websites and reaches more than 100,000
designers and developers monthly.

The core philosophy of One Page Love centers on brevity and narrative focus:
websites that tell a complete story, present a product, or pitch a portfolio
without linking off to separate multi-page hierarchies. It accepts single-page
experiences with smooth in-page anchor scrolling and essential utility links
(terms, privacy, support).

In addition to inspiration, the platform features a curated template directory
housing over 300 templates (over 100 free templates alongside nearly 200 premium
commercial templates) built with modern frameworks such as HTML5, Tailwind CSS,
Next.js, Framer, Webflow, and Carrd.

## Paywall and pricing

- **Free:** Browsing the 9,000+ single-page showcase, filtering by style and
  technology, submitting websites for editorial review, and downloading over 100
  free website templates are completely free.
- **Paid:** Premium marketplace templates are individually priced (typically
  ranging from $19 to $79 one-time). Standard website submission is free for
  review.
- **API access:** One Page Love provides an official API (`onepagelove.com/api`)
  with a free tier granting access to clean JSON across 9,000+ curated websites
  with Retina screenshots and metadata.
- **Sign-up required?** Browsing and free template downloads require no login.
  An account is needed to purchase premium templates or generate an API key.
- **Licence for client work:** Free templates vary by author (frequently MIT or
  Creative Commons). Premium templates include commercial licenses for single or
  unlimited client projects depending on the tier.

## How to use

1. Select single-page archetype: Filter by category (e.g., Portfolio, SaaS, App,
   Event, or Personal) to find layout structures suited to the TolongLabs build.
2. Study in-page anchor storytelling: Analyze how winning one-pagers structure
   visual pacing, maintain scroll momentum, and position primary
   call-to-actions.
3. Utilize templates: Download free HTML/Tailwind templates or purchase premium
   Framer/Webflow templates to jumpstart client delivery.
4. Integrate API into agent workflows: Query the One Page Love API to fetch
   curated layout examples and section tags programmatically:

```bash
# Query One Page Love API for SaaS single-page inspiration
curl -s "https://onepagelove.com/api/v1/websites?category=saas" \
  -H "Authorization: Bearer YOUR_API_KEY"
```

## When to use it

- Use it when designing focused single-page marketing sites, mobile app launch
  pages, personal portfolios, or webinar registration pages.
- Use it when you need verified, production-ready one-page templates in Tailwind
  or HTML.
- Skip it when building large content hubs, enterprise docs, or complex
  multi-page e-commerce stores; choose
  [SiteInspire](../design-galleries/siteinspire.md) or
  [Best Website Gallery](../design-galleries/best-website-gallery.md) instead.

## Agent notes

- Highly agent-friendly: One Page Love provides an official REST API at
  `https://onepagelove.com/api` delivering structured JSON for curated websites,
  tags, platforms, and page section screenshots.
- Coding agents can query the API or parse template source files to automate
  moodboard assembly and layout scaffolding.
- When generating single-page sites, adhere to the platform's standard: anchor
  navigation, unified scroll container, and persistent top/floating CTA.
