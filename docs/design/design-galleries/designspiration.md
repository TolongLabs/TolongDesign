## What it is

Designspiration is an image-led visual discovery and inspiration engine founded
in 2010 by designer and developer Shelby White. Built as a focused, high-taste
alternative to generic image-sharing websites, it serves an international
community of graphic designers, art directors, architects, and web creators.

The platform is renowned for its color-search capability. Users can select up to
five complementary hex colors or pick from an intuitive palette picker, and
Designspiration will index photographs, posters, packaging, brand guidelines,
and web interfaces that match that exact color harmony.

Beyond individual image discovery, the platform features "Visions"—a
moodboarding tool allowing users to organize visual references into structured
grids. Designers can collect inspiration from across the web using the official
browser extension, organize boards by project, and extract color swatches
directly from saved images.

## Paywall and pricing

- **Free:** Free basic membership allows browsing the visual library, executing
  color and keyword searches, saving images into public collections, and using
  the browser extension (ad-supported).
- **Paid:** Pro membership provides an ad-free interface, unlimited private
  moodboards, high-resolution exports (PNG, PDF), custom board layouts, and
  priority support. Pro is priced at $5/month or $50/year.
- **Sign-up required?** Basic browsing is open; creating a free account is
  required to save boards, follow creators, or use the color-search engine.
- **Licence for client work:** Images displayed on Designspiration remain the
  copyright of their respective photographers, illustrators, and designers. They
  are intended strictly for conceptual moodboards and internal visual
  references.

## How to use

1. Conduct hex color searches: Input client brand colors or target palette hex
   values into the color picker to see how those tones behave in real
   photography, print, and interface design.
2. Build project "Visions": Create dedicated moodboards for TolongLabs projects
   to collect typography samples, texture references, and layout treatments.
3. Use the browser extension: Capture visual references from live client
   websites or competitor benchmarks directly into organized Designspiration
   boards.
4. Extract palette swatches: Generate color balance references from assembled
   moodboards to guide CSS token definitions and Tailwind color scales.

## When to use it

- Use it when establishing early visual direction, brand color palettes, or
  creative art direction for new client engagements.
- Use it to explore how specific color combinations feel across varied media
  before writing CSS.
- Skip it when looking for pre-coded Tailwind components or concrete frontend
  code snippets; use [Landingfolio](../design-galleries/landingfolio.md)
  instead.

## Agent notes

- Visual platform without a public API or programmatic endpoints.
- Color search relies on client-side canvas and web application state.
- Coding agents can advise developers on color codes extracted from moodboards
  and suggest complementary palette tokens for Tailwind configurations.
