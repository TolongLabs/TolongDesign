## What it is

Appinspo is a curated online design gallery created by digital designer Jordi
Plz (@jordiplz) dedicated to highlighting current visual aesthetics in mobile
application design. Built as a focused alternative to noise-heavy platforms like
Dribbble and Pinterest, it documents production-ready mobile screens that blend
modern graphic craft with functional UI design.

The platform indexes screens from leading consumer and enterprise mobile
applications across categories such as finance, social networking, health,
productivity, travel, and AI tools. Each entry highlights modern mobile
interface conventions: floating navigation pills, blurred glassmorphic header
treatments, bento-grid dashboard cards, tactile slider controls, and clean
typography.

Rather than cataloguing complex multi-step technical user flows, Appinspo
focuses on the visual and spatial quality of the screens. It serves as an
immediate visual touchstone for mobile UI designers refining color palettes,
shadow elevations, corner radiuses, and typographic proportions.

## Paywall and pricing

- **Free:** Browsing all mobile screen collections, filtering by tags, and
  creating personal boards are completely free.
- **Paid:** No paid subscriptions, pro plans, or paid listing fees.
- **Sign-up required?** Browsing the gallery is completely public without an
  account. Free account sign-up (via Google auth) is available for users wishing
  to create custom boards and save references.
- **Licence for client work:** Screenshots represent proprietary mobile
  applications and their respective brand assets. Designs serve as inspirational
  benchmarks and reference material.

## How to use

1. Filter by application domain: Browse categories (e.g., Finance, Productivity,
   AI Tools) to find current visual norms in your project's sector.
2. Analyze UI styling details: Inspect how top applications handle card
   elevations, border contrast, dark mode accents, and iconography sizing.
3. Save screens into boards: Group related screens into custom boards to share
   with design teams or client stakeholders.
4. Translate styling into code tokens: Extract spacing scales, corner radius
   standards (e.g., `rounded-2xl`, `rounded-3xl`), and color accents into your
   Tailwind or React Native theme file.

## When to use it

- Use it when designing modern iOS applications or mobile-first responsive web
  apps.
- Use it to study contemporary aesthetic details—such as card nesting, bottom
  sheets, and typography contrast.
- Skip it when you need step-by-step onboarding teardowns or conversion funnels;
  consult [UX Archive](../design-galleries/ux-archive.md) or
  [Screenlane](../design-galleries/screenlane.md) instead.

## Agent notes
