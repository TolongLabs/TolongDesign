## What it is

Mobbin indexes screens, UI elements, animations, and user flows from shipped
mobile apps and websites. Its site reports more than 621,500 screens and new
material each week; the library is searchable by app, interface pattern, and
text in screenshots.

The service supports saving collections, copying designs to Figma, and reviewing
multi-screen flows. Its Mobbin MCP lets supported coding agents search the
library and use references in a build conversation.

## Paywall and pricing

- **Free** The Free plan allows limited app and site browsing, limited
  copy/download, and up to three collections. An account is required.
- **Paid** Pro is $10/month billed yearly for one member. Team is
  $16/member/month billed yearly. Enterprise is custom. Finance+ is a $399/month
  yearly add-on for teams.
- **Sign-up required?** Yes. Join for free to access the library; paid access is
  needed for full screens, flows, collections, and MCP.
- **Licence for client work** The library is a research reference, not a license
  to ship third-party screens or assets. Obtain rights from the original product
  owner before reuse.

Pricing and availability checked 2026-10-07.

## How to use

1. Create a free account, choose Apps or Sites, then search by product name,
   screen type, or a user journey such as onboarding, checkout, or settings.

2. Use filters to compare examples from different products. Open the flow view
   when sequence and transitions matter; use individual screens for layout and
   copy.

3. Save a small set to a collection and add notes about the pattern, user goal,
   and trade-offs. Copy to Figma only as a research aid.

4. For a coding agent, connect Mobbin MCP from a paid Pro or Team account, then
   ask for a focused pattern set and summarize the observations before
   implementation.

## When to use it

- Use it when a team needs real mobile or web product screens, flow sequences,
  or agent-accessible UI evidence.
- Skip it when the brief is mainly about a marketing-site aesthetic; use
  [Curated Design](../design-galleries/curated-design.md) or
  [Saaspo](../design-galleries/saaspo.md).

## Agent notes

- Official MCP: https://mobbin.com/mcp. It is listed for Pro and Team plans; the
  site says setup takes under a minute and requires no API key.
- Keep prompts narrow, such as “compare three mobile account-setup flows.” Do
  not ask the agent to reproduce a named product screen pixel for pixel.
