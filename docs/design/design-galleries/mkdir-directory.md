## What it is

mkdir.directory is a small, hand-curated directory of **web design inspiration
directories** — "picked by hand and kept short on purpose." Itself an
inspiration site, it points at the galleries worth browsing rather than at
individual designs. Its one section, **Directories (34)**, lists galleries,
award sites, landing page collections and section libraries such as Awwwards,
One Page Love, Siteinspire, Land-book, The FWA, Codrops Creative Hub and
loadmo.re.

Its filter is strict: "Only directories of links (websites, posts or other
links), free to explore with no paywall or account, are accepted." The ranking
is community-driven: "Visitors vote for the ones they use, one vote per
directory," and "the list is ranked by those votes." Each row shows its rank and
vote count — Awwwards leads with 416 votes, loadmo.re trails with 2.

For TolongLabs it is most useful as a **discovery shortcut**: when a project
needs references, this picks which galleries to open before any of the repo's
per-gallery docs.

## How to use

1. Open [mkdir.directory](https://mkdir.directory/) and skim the ranked list —
   the top of the list is the community's current favourite hunting ground.
2. Click through to the directories that match the brief: galleries for general
   browsing (Awwwards, Land-book, Siteinspire), niche pattern sites (Navbar
   Gallery, Footer.design, Unsection), collections with a theme (Dark.Mode,
   brutalist and minimal directories, loadmo.re).
3. Vote for the directories you actually use if you want the ranking to move.
4. To suggest a missing directory, use the submit form on the site; only free,
   no-account link directories are accepted.
5. Turn what you find into a brief: keep the underlying gallery docs in this
   repo ([Awwwards](awwwards.md), [Land-book](land-book.md),
   [One Page Love](one-page-love.md), …) for the per-site workflows.

## Examples

- [The ranked list](https://mkdir.directory/) — the whole product: 34
  directories ranked by votes; note which niche sites (404s for 404 pages,
  Storefolio for e-commerce, Recent for fresh work) a project brief needs.
- [Awwwards (rank 1, 416 votes)](https://www.awwwards.com) — the top-ranked
  destination; shows how the community weighs established award sites over newer
  galleries.
- [loadmo.re (rank 34, 2 votes)](https://loadmo.re) — the long tail; useful to
  spot freshly submitted niche directories before they rank.

## When to use it

- Use it when starting reference research and unsure which galleries to open, or
  when looking for a niche directory (footers, 404 pages, e-commerce,
  one-pagers, dark mode, brutalism) without browsing the long lists here first.
- Skip it when you already know the target gallery — go straight to its doc in
  this repo: [Siteinspire](siteinspire.md), [Collect UI](collect-ui.md),
  [Mobbin](mobbin.md), [Best Designs on X](bestdesignsonx-com.md) and ~75 more
  covered individually. It also carries no designs itself, so it never replaces
  the galleries it links to.

## Agent notes

- Single-page static directory with no search, API, llms.txt or MCP server.
- No per-entry metadata beyond rank, name, domain and vote count — an agent
  cannot judge entries without visiting the linked sites.
- Rank numbers are vote tallies, not editorial scores; treat them as popularity
  signals only.
- All 34 entries overlap heavily with this repo's Design Galleries section,
  which holds deeper per-site docs; use mkdir.directory to check for directories
  not yet catalogued here.
