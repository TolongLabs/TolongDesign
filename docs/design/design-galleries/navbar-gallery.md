## What it is

Navbar Gallery (`navbar.gallery`) is a focused design inspiration directory
created by web designer, Webflow developer, and indie maker Christina Liubynska
(@suupercharged). Inspired by component-specific archives like footer.design,
the platform was launched to solve a recurring challenge in web design: planning
and structuring effective website navigation.

Website navigation bars must satisfy demanding functional constraints—housing
brand identity, primary product taxonomy, resource links, authentication
triggers, and primary call-to-actions within a compact, responsive viewport
container. Navbar Gallery isolates and indexes these headers from top SaaS,
agency, and e-commerce websites.

The gallery classifies navigation patterns into distinct architectural types:
floating static navbars, interactive dropdowns, multi-column mega-menus,
vertical sidebars, search-integrated bars, top announcements, full-screen mobile
overlays, and breadcrumb chains.

## How to use

1. Choose navigation taxonomy: Determine the content density needed for the
   TolongLabs project (e.g., standard dropdowns for a simple marketing site vs.
   a full mega-menu for a complex multi-product SaaS platform).
2. Filter by navbar style: Navigate to specific categories (e.g.,
   `/type/mega-menu`, `/type/side-bar`, or `/type/dropdowns`).
3. Deconstruct IA and grouping: Examine how leading sites group child links,
   integrate product badges, incorporate micro-descriptions, and position auth
   buttons.
4. Implement component structure: Translate the chosen navigation pattern into
   accessible HTML/ARIA components using Tailwind CSS, Radix UI, or React Aria.

## When to use it

- Use it when designing or restructuring the global header and navigation for a
  marketing site or web application.
- Use it to study how top sites organize complex information architectures into
  approachable mega-menus.
- Skip it when you need complete full-page landing page flows or footer layouts;
  consult [Landingfolio](../design-galleries/landingfolio.md) or
  [One Page Love](../design-galleries/one-page-love.md) instead.

## Agent notes

- Visual pattern showcase built on Webflow without a public API or CLI tool.
- When generating navigation components, agents should ensure accessible ARIA
  attributes (`aria-expanded`, `aria-haspopup`, keyboard focus rings) that match
  the structural layouts seen on Navbar Gallery.
- Navbars shown are real-world web implementations; reference them to validate
  responsive hamburger-to-desktop breakpoint decisions.
