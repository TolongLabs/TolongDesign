## What it is

Flowbase is an established design resource platform and component repository
focused on no-code and visual website development environments. Specifically
tailored for Webflow, Figma, and Framer practitioners, Flowbase offers thousands
of modular UI blocks designed to be pasted directly into project canvases.

The library encompasses more than 3,500 premium components, 1,000+ wireframes,
1,000+ vector illustrations, and over 15,000 custom icons. Rather than requiring
developers to code standard layouts from scratch, Flowbase provides responsive
sections for navigation bars, hero layouts, pricing grids, testimonials, contact
forms, and footers.

In addition to static layouts, Flowbase provides Webflow Boosters—custom
JavaScript scripts and interaction snippets that add client-side functionality
such as advanced filtering, accordion state management, and copy-to-clipboard
interactions without custom backend infrastructure.

## Paywall and pricing

- **Free:** Starter plan includes access to a collection of 100+ free
  components, standard assets, and free plugin tools. Users can copy up to 10
  components without an account, after which a free registration is required.
- **Paid:** Club Pro+ plan costs $39/month on monthly billing or $27/month
  billed annually ($324/year). Monthly subscriptions are subject to 200
  component copies per month; annual plans grant unlimited component and asset
  copying.
- **Sign-up required?** Yes, a free account is needed after copying 10
  components.
- **Licence for client work:** Club components and assets may be used on
  unlimited commercial and client projects. Reselling or redistributing raw
  Flowbase assets in template marketplaces is prohibited.

Verified on the official Flowbase pricing page on 2026-10-07.

## How to use

1. Install the appropriate extension: Add the Flowbase Chrome extension or
   install the official Flowbase plugin in Figma or Framer.
2. Select target platform: Toggle between Webflow, Figma, or Framer views in the
   component directory depending on the current design canvas.
3. Copy and paste components: Browse categories (e.g., Navbars, Heroes, or
   Pricing Tables), click "Copy Component", and paste directly onto the visual
   canvas. Note: Chrome or Firefox is recommended; Safari clipboard handling can
   interfere with canvas copying.
4. Customize styles and tokens: Update color swatches, typography classes, and
   responsive layout breakpoints to conform to the TolongLabs project design
   system.

## When to use it

- Use it when rapidly building marketing websites or client prototypes in
  Webflow, Figma, or Framer.
- Use it to grab tested responsive layouts for standard landing page sections.
- Skip it when writing custom React or Tailwind CSS code directly; use
  [Landingfolio](../design-galleries/landingfolio.md) for copy-paste Tailwind
  code blocks instead.

## Agent notes

- Not agent-friendly for automated code generation: Flowbase components are
  designed for clipboard-based visual pasting into proprietary design tools
  (Webflow / Figma / Framer) and do not provide an npm package or raw code CLI.
- When assisting human developers working in Webflow or Figma, agents can
  recommend specific Flowbase component categories to speed up visual assembly.
