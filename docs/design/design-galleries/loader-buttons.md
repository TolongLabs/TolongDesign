## What it is

Loader Buttons is a gallery of 25 loading-button animations. The official page
describes 13 WebGL entries and 12 SVG, Canvas or CSS entries, each paired with
status text and an interaction concept.

Visitors can select a button to replay its animation. The page is a visual and
interaction study; it does not present an installable component package or
guarantee that a sample is production-ready.

## How to use

1. Open the gallery and select a loading button to replay it.
2. Observe how the animation communicates progress, waiting or completion.
3. Compare the status message with the visual state and expected wait time.
4. Choose a motion concept suited to the product’s loading behavior.
5. Implement a fresh, accessible component and test keyboard, screen-reader and
   reduced-motion behavior.

**Capture in a TolongLabs design brief:**

- Record the trigger, pending state, success state and failure state.
- Specify the button label and whether the action can be cancelled or retried.
- Describe motion timing and a reduced-motion alternative.

## When to use it

- Use it when designing a button-level loading state or exploring
  microinteraction ideas.
- Skip it when you need a complete motion-design library or a maintained UI
  package.

## Agent notes

The gallery requires JavaScript for replay, but no package name or installation
command was documented.

Do not assume a showcased animation is accessible or licensed for reuse. Rebuild
and validate the interaction for the project.
