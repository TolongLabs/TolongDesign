## What it is

Backgrounds Supply sells a curated library of handcrafted gradients,
AI-generated visuals, and animated MP4 backgrounds for web, social,
presentation, and motion work. It provides a web interface for browsing
collections and a Gradient Lab tool.

The free sample uses the same resolution files as the paid pack, but the free
download is personal-use only. The one-time purchase includes commercial use and
future drops. Published inventory totals vary between the homepage and detailed
pages, so verify the current library before buying.

## Paywall and pricing

- **Free** A set of free preview backgrounds is available after email sign-in,
  without a card. The detailed freebie page limits these previews to personal
  use.
- **Paid** The full collection is $49 one-time with lifetime access, future
  drops, and a commercial license for client work, websites, apps, ads,
  presentations, and motion projects.
- **Sign-up required?** Email is required to download free previews. The full
  purchase is a one-time checkout.
- **Licence for client work** Free preview files are personal-use only. The $49
  purchase includes commercial and client-work use; reselling or redistributing
  the files as a standalone product is not allowed.

Pricing and availability checked 2026-10-07.

## How to use

1. Browse the Wallpapers page by collection and visual mood. Use the free
   preview page to assess image quality before purchasing.

2. Choose a static background for a hero, card, slide, or product mockup;
   reserve animated MP4 files for motion contexts where they add meaning.

3. Download a sample or purchase the full library, then import the image into
   Figma, Framer, Photoshop, Canva, Webflow, or another tool that accepts
   uploads.

4. For a client project, confirm the purchase covers the intended commercial
   use. Optimize dimensions, format, and contrast for the page before shipping.

## When to use it

- Use it when a project needs ready-made background imagery and the client can
  clear the asset license.
- Skip it when you need assets that are all free for commercial use; use
  [Venust Backgrounds](../design-galleries/venust-backgrounds.md).

## Agent notes

- No public API, MCP server, CLI, or code package was listed. A coding agent can
  use a purchased and locally supplied image path, but should not fetch or
  commit third-party assets without project approval.
- Record the purchase and license scope with the asset in the client project.
  The gradient generator is a browser tool, not a documented build dependency.
