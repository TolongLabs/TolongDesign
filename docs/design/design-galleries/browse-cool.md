## What it is

Browse.cool is an independent web design gallery focused on digital experiences
with exceptional tactile feedback, distinctive typography, and rich visual
texture. Curated by Ali (aaali.xyz), the site maintains an evolving index of
curated sites and high-resolution shots selected specifically for their tangible
interactive quality.

While mainstream galleries often prioritize standardized B2B conversion
templates, Browse.cool spotlights websites that simulate physical materials,
kinetic motion, organic shapes, and unexpected typography scales. Its index
highlights projects from cutting-edge design studios, architecture practices,
and boutique physical brands.

Each entry includes high-frame-rate video previews, static snapshots, and direct
hyperlinks to live URLs, allowing visitors to inspect how tactile feedback is
achieved through CSS transitions, smooth scrolling, and interactive canvas
layers.

## How to use

1. Visit `https://browse.cool/` and toggle between full-site showcases
   (`Browse Sites`) and specific interaction captures (`Shots`).
2. Filter through featured projects to evaluate how high-end brands implement
   cursor reactivity, tactile button states, and smooth drag mechanics.
3. Open the live site links to inspect runtime performance, font choices, and
   framerate in desktop and mobile viewports.
4. Translate tactile concepts—such as subtle spring physics, depth shadows, or
   brutalist type treatments—into TolongLabs animation specs using libraries
   like Motion.

## When to use it

- Use it when designing high-end portfolio sites, creative agency presentations,
  or bespoke luxury brand web experiences.
- Use it to discover subtle tactile animation patterns, cursor magnetism, and
  layered depth styling.
- Skip it when building utility-first SaaS dashboards or dense administrative
  interfaces; consider
  [Best SaaS Web Designs](../design-galleries/best-saas-web-designs.md) or
  [Sections.wtf](../design-galleries/sections-wtf.md) instead.

## Agent notes

- The site is built with Framer and provides no machine-accessible API, CLI, or
  structured data feeds.
- Coding agents can cite specific Browse.cool URLs when recommending motion
  behaviors or visual mood boards during creative discovery phases.
- Projects showcased often depend on advanced animation techniques such as
  WebGL, Lenis smooth scrolling, or GSAP/Motion spring configurations.
