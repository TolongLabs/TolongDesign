## What it is

Sections.wtf is a curated inspiration gallery that catalogs live website
components isolated into specific section patterns. Created by independent
designer Ali (aaali.xyz), the site archives production UI examples cut from
modern SaaS startups, creative agencies, and developer tool landing pages.

Rather than presenting entire page screenshots where subtle block layouts get
lost, Sections.wtf organizes captures strictly by component role. Visitors can
filter into distinct functional blocks including Hero, Bento, Pricing, CTA,
Features, Navigation Menu, Testimonial, FAQ, Roadmap, Team, Footer, 404,
Statistics, Form, Open Graph cards, and Tabs.

Each cataloged entry displays high-resolution visual crops of the live interface
alongside direct attribution to the source product. This makes it an effective
tactical reference when drafting design specs for individual page segments.

## How to use

1. Identify the specific page block needed for a TolongLabs project (for
   example, a feature bento grid or pricing matrix).
2. Navigate to `https://sections.wtf/` and select the target filter tag at the
   top bar (such as `Bento`, `Pricing`, or `CTA`).
3. Examine high-performing visual hierarchies, responsive spacing choices, and
   typography treatments in the filtered results.
4. Extract interaction and layout ideas into your project design brief or Figma
   board, pairing the structural pattern with TolongLabs component primitives.

## When to use it

- Use it when designing a specific section of a marketing page and needing
  focused inspiration for layout, visual weight, or copy density.
- Use it to study real-world bento layouts, pricing cards, and interactive CTA
  treatments from venture-backed software products.
- Skip it when looking for full-page customer journeys or multi-page user flows;
  use [SaaS Landing Page](../design-galleries/saas-landing-page.md) or
