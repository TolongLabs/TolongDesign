## What it is

SiteInspire is a long-standing, hand-curated showcase of web and interactive
design craft. Founded and curated by designer Daniel Howells (Howells-Studio),
the platform documents websites that demonstrate visual discipline, balanced
composition, and refined typographic hierarchy.

The gallery houses an extensive archive of thousands of reviewed websites.
Unlike award aggregators that celebrate heavy 3D WebGL or flashiness,
SiteInspire emphasizes practical, elegant, and functional web design. Entries
represent design studios, independent creatives, architecture firms, fashion
labels, and independent digital publications.

What sets SiteInspire apart from typical landing page galleries is its
sophisticated multi-axial tagging system. Users can filter and combine criteria
across visual styles (such as minimal, editorial, or colorful), functional types
(portfolios, corporate, e-commerce), subject matters, and underlying web
platforms.

## Paywall and pricing

- **Free:** Browsing the full archive of curated websites, using multi-tag
  filters, and submitting projects for editorial consideration are completely
  free with no fee.
- **Paid:** No paid subscriptions, listing tiers, or pro upgrades.
- **Sign-up required?** Optional. Browsing and filtering require no account.
  Creating a free user account lets visitors save websites into personal
  collections.
- **Licence for client work:** Featured websites remain the copyrighted property
  of their respective studios, agencies, and clients. Layouts and visual
  treatments serve as conceptual benchmarks and reference inspiration.

## How to use

1. Define aesthetic criteria: Identify the visual posture required for the
   TolongLabs project (for example, a clean portfolio or an editorial studio
   site).
2. Apply combined filters: Use SiteInspire's filtering menu to cross-reference
   styles (e.g., "Minimal" or "Typographic") with types (e.g., "Studio" or
   "Corporate") and specific platforms.
3. Evaluate structural treatments: Inspect live sites in desktop and mobile
   viewports to study typographic hierarchy, margin proportions, whitespace
   ratios, and restrained micro-interactions.
4. Translate into design briefs: Capture reference URLs and screenshot links to
   specify typographic pacing, grid structures, and content layouts in project
   documentation.

## When to use it

- Use it when designing editorial websites, agency portfolios, architecture
  portals, or minimalist product homepages requiring refined craft.
- Use it when seeking real-world inspiration for grid systems, elegant
  typography, and subtle transitions.
- Skip it when building component-heavy B2B SaaS web apps or dashboard
  interfaces; consult [Landingfolio](../design-galleries/landingfolio.md) or
  [SaaSFrame](../design-galleries/saasframe.md) instead.

## Agent notes

- Visual gallery only: SiteInspire does not offer a public API, npm package, CLI
  utility, or `llms.txt` file.
- The site operates behind Vercel bot mitigation, preventing unauthenticated
  automated scraping or headless browser fetches.
- Agents should use SiteInspire URLs as external conceptual benchmarks when
  drafting design specifications or visual mood boards for developers.
