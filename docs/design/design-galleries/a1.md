## What it is

A1 (a1.gallery) is a curated digital design inspiration platform founded in 2024
by designer Bryn Taylor. Updated daily, the archive indexes more than 1,225
standout websites, 3,250 captured sections, 3,000 full-page screenshots, 570
curated typography pairings, and 540 leading digital creators.

What sets A1 apart from standard web galleries is its technical architecture
geared towards AI-assisted engineering workflows. Alongside standard visual
filtering (by layout type, technology, color palette, and industry), A1 provides
an official Model Context Protocol (MCP) server. This server exposes 17
specialized tools—such as `search_websites`, `browse_websites`, and
`get_website`—enabling AI coding tools to query design references directly from
the editor.

The gallery indexes comprehensive design systems: visitors can examine full
desktop and mobile pages, isolate distinct section components (heros, pricing,
footers, OG images), and discover the exact web fonts used across production
sites.

## Paywall and pricing

- **Free:** Browsing the entire catalog of 1,000+ websites, filtering by style,
  color, font, and technology, saving up to 30 sites across 2 boards, creator
  profiles, and standard-tier MCP server access are 100% free with an account.
- **Paid:** Pro membership is priced at $10/month billed monthly, or $7/month
  billed annually ($84/year):
  - 40× higher MCP server rate limits.
  - Unlimited site saves and unlimited mood boards.
  - High-resolution full-page screenshot downloads.
  - Prioritized site submission reviews.
  - Ad-free browsing experience and early access to new features.
- **Sign-up required?** No sign-up required for public browsing. Free account
  required for saving collections or connecting to the MCP server.
- **Licence for client work:** Screenshots and designs are owned by the
  respective featured brands and creators. Use for conceptual benchmarking and
  creative direction.

## When to use it

- Use it as your primary visual inspiration engine when needing font pairings,
  modular section layouts, and full-page references in one place.
- Use it within AI coding agents (Claude Code, Cursor, Windsurf) by connecting
  to its native MCP server for automated design benchmarking.
- Skip it when you need raw copy-paste component source code; use
  [shadcn/ui](../component-libraries/shadcn-ui.md) or
  [21st.dev](../component-libraries/21st-dev.md) instead.
