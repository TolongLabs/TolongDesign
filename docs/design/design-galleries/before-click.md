## What it is

before.click is an inspiration gallery for App Store screenshots, onboarding,
paywalls and app icons. The home page groups app records and supports browsing
by platform and category, with search and curated or recent selections.

The site also publishes an App Store Optimization skill for agents. Gallery
images and app branding belong to their respective owners, so use the examples
to study communication and sequencing rather than as reusable art.

## Paywall and pricing

- Free: The public gallery can be browsed without a paid plan.
- Paid: No reader subscription was published on the official site.
- Sign-up required? No for browsing; account actions such as saving may need
  sign-in.
- Licence for client work: App screenshots and icons remain owned by their app
  creators.

The access and pricing details above were checked on 2026-10-07.

## How to use

1. Open the gallery and browse screenshot, onboarding, paywall or icon material.
2. Search for an app, visual style or category, and narrow by iPhone or Mac
   where available.
3. Open an app record and inspect the screenshot sequence, store context and
   visible metadata.
4. Compare how examples communicate value and guide a first-time user.
5. Use the official ASO skill only after reviewing its repository and command
   instructions.

**Capture in a TolongLabs design brief:**

- Describe the app category, audience and promise in the first store impression.
- Record screenshot sequence, headline length, contrast and feature progression.
- Keep store conversion concepts separate from in-product onboarding
  requirements.

  broader results.

## When to use it

- Use it when planning App Store imagery or comparing mobile onboarding and
  paywall presentation.
- Skip it for web landing-page references; use Landing Love or CTA.gallery.

## Agent notes

The official site links an ASO skill install command:
`npx skills add alexszczurek/before-skills`. Review that repository before
running it in a project.

The `explore?app=` examples are dynamic filters, not stable detail pages; a page
check can show the broader gallery rather than the selected app. No public API
was verified.
