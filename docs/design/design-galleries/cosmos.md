## What it is

Cosmos is a visual reference library where members save images, links, video,
products, and notes as elements, then organize them into public or private
collections. The web app and mobile app share the same account and collections.

Its search supports themes, aesthetics, and color palettes. The For You feed
responds to saved and followed material. Browser extensions add references from
other sites without downloading the original asset.

## Paywall and pricing

- **Free** Anyone can browse public profiles and collections. A free account
  supports saving and organizing references; the help center says Premium is
  optional.
- **Paid** Cosmos Premium adds custom usernames, early features, collection
  collaboration, bulk export, and grid controls. Price: Not published on the
  official Premium and FAQ pages checked.
- **Sign-up required?** No account is needed to view public pages. Sign-in is
  needed to save, create, or follow collections.
- **Licence for client work** Cosmos licenses its image and link content only as
  third-party references; it does not grant rights to reuse saved work in a
  client deliverable.

Pricing and availability checked 2026-10-07.

## How to use

1. Open Search or Discover and search a subject, visual style, or color palette.
   Browse public profiles and collections before making an account.

2. Save useful material as elements, then group it into a project collection.
   Use separate collections for brand, layout, photography, and interaction
   references.

3. Add a short note to each saved item explaining the design quality to study,
   such as contrast, crop, composition, or material.

4. Turn the collection into a TolongLabs brief: record the desired mood,
   palette, type scale, layout cues, and three references. Link to originals
   instead of copying images into the codebase.

## When to use it

- Use it when the team needs to collect visual direction from many kinds of
  sources in one shareable board.
- Skip it when you need shipped web-page patterns with implementation detail;
  use [Details](../design-galleries/details.md) or
  [Mobbin](../design-galleries/mobbin.md).

## Agent notes

- No public MCP server, API, CLI, or code package was listed in the official
  pages checked. Use a public collection URL as human-readable context for a
  coding agent.
- Do not export or commit third-party images as project assets. Premium export
  is for saved collection images, not an asset license.
