## What it is

What Ships curates startup launch videos, product demos and walkthroughs
originally posted on X. The gallery can be searched and filtered by areas such
as AI, developer tools, design, motion, productivity, consumer and hardware.

The site also publishes developer resources, an llms.txt file, a search index
and an OpenAPI document. These provide a direct way for coding agents to
discover catalogue entries while preserving links to the source posts.

## Paywall and pricing

- Free: Public browsing and the documented machine-readable resources are
  available without payment.
- Paid: No reader subscription or API fee was published in the developer
  resources checked.
- Sign-up required? No authentication is documented for the public resources.
- Licence for client work: Videos and product work belong to their creators;
  links do not grant reuse rights.

The access and pricing details above were checked on 2026-10-07.

## How to use

1. Browse by category or use the site search to find a product or demo style.
2. Open a video record and follow its original X post for context.
3. For automation, read the developer page and llms.txt before using the search
   index or OpenAPI description.
4. Use results to study demo structure, pacing and feature framing.
5. Link both the What Ships record and original post in a project brief.

**Capture in a TolongLabs design brief:**

- Record the product, audience, demo goal and original post URL.
- Describe the sequence of feature reveal and the narration or cursor behavior.
- Translate the observation into a new script and capture plan.

## When to use it

- Use it when planning a startup launch video or studying how products
  demonstrate value.
- Skip it when you need polished motion references outside the product-launch
  context; use Motionimo.

## Agent notes

Read `https://whatships.com/llms.txt` and the developer page before agent use.
The site exposes `/search-index.json` and `/openapi.json`; docs state public
access without authentication and no MCP or webhooks.

Use the original X post as the source of truth. Do not download, reproduce or
train on the linked video.
