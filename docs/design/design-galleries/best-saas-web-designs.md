## What it is

Best SaaS Web Designs (bestsaaswebdesigns.com) is a curated design repository
indexing more than 400 standout SaaS websites and landing pages. Curated by
product designer Derek, the platform combines high-resolution full-page captures
with technical metadata that traditional galleries omit.

For each indexed website, Best SaaS Web Designs documents the underlying
frontend technology stack (such as Next.js, React, Tailwind CSS, Framer,
Webflow, or Vercel) alongside the precise hexadecimal color palette extracted
from the branding. This enables developers to understand both how a site looks
and the engineering choices that made it possible.

The platform provides dual browsing modes: users can evaluate complete landing
pages or drill down into modular section libraries covering Hero Sections,
Feature Sections, Pricing Pages, Footers, Testimonials, Call to Action blocks,
FAQ accordions, and Logo Clouds.

## How to use

1. Open `https://bestsaaswebdesigns.com/` and filter by Page Type, Industry
   Category, Visual Style, or Frontend Stack.
2. Select a company profile (such as Tavus, Plasmic, or Clerk) to inspect the
   full-page layout alongside the extracted hex color swatches.
3. Review the documented frontend technologies to verify whether a particular
   visual aesthetic was achieved using Tailwind, custom CSS, or no-code tools.
4. Navigate to `/sections/hero-sections` or `/sections/pricing-pages` when
   benchmarking specific modular page components.
