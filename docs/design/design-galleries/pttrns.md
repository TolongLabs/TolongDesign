## What it is

Pttrns is one of the earliest and most recognized design pattern libraries
dedicated to mobile user interfaces. Founded in Prague in 2011 by Robin Raszka,
the platform was created to catalog the emerging design paradigms of iOS and
Android applications into a structured, searchable taxonomy.

The platform indexes thousands of mobile screenshots organized by interaction
patterns and UI components. Rather than grouping items solely by brand, Pttrns
categorizes screens by specific mobile UI problems: tab bars, navigation
drawers, activity feeds, profile cards, search filters, checkout screens, media
players, and empty states.

By organizing screens by component type across generations of mobile operating
systems, Pttrns serves as an authoritative historical and contemporary reference
for mobile product teams evaluating ergonomics, tap target placements, and
visual hierarchy on touchscreen devices.

## Paywall and pricing

- **Free:** Pttrns is completely free to use. Users can browse the entire
  archive of thousands of mobile patterns across all categories without any
  subscription fee.
- **Paid:** No paid plans, recurring subscriptions, or locked premium tiers.
- **Sign-up required?** Optional. Browsing the library is accessible publicly;
  creating a free account allows users to bookmark patterns and organize them
  into custom collections.
- **Licence for client work:** Screen designs remain the intellectual property
  and copyright of their respective mobile application publishers. They serve as
  reference material and UX benchmarks.

Verified on the official Pttrns website on 2026-10-07.

## How to use

1. Select component or pattern category: Navigate to the category list and
   choose the interface component under active design (e.g., Walkthroughs,
   Filters, Cards, or Settings).
2. Filter by device ecosystem: Review iOS and Android patterns side-by-side to
   understand native platform conventions and human interface guideline
   differences.
3. Assess thumb-zone ergonomics: Study how top mobile apps position primary
   call-to-actions, bottom sheets, and floating buttons for single-handed
   usability.
4. Integrate into mobile wireframes: Document chosen pattern conventions in
   TolongLabs design specifications or React Native / Flutter screen layouts.

## When to use it

- Use it when designing mobile applications in React Native, Flutter, iOS
  (SwiftUI), or Android (Jetpack Compose).
- Use it to verify how standard mobile patterns (tab bars, sheets, list cards)
  are solved across production apps.
- Skip it when designing desktop-first SaaS web dashboards or marketing landing
  pages; use [Landingfolio](../design-galleries/landingfolio.md) or
  [SaaSFrame](../design-galleries/saasframe.md) instead.

## Agent notes

- Visual mobile archive without a public API, npm package, or CLI tool.
- Coding agents can reference Pttrns category paths when providing human
  developers with mobile UI layout benchmarks and architectural recommendations.
- Screenshots are copyrighted mobile assets; do not clone branded artwork or
  icons directly into production applications.
