## What it is

v0 is an AI-powered generative user interface and full-stack web application
builder developed by Vercel. It transforms natural-language prompts, wireframe
sketches, and visual screenshots into accessible, composable React components
styled with Tailwind CSS and backed by the shadcn/ui component ecosystem.

Unlike general-purpose conversational LLMs that output fragmented code snippets,
v0 renders interactive previews in an isolated browser canvas. Users can tweak
layouts visually using a dedicated Design Mode, inspect rendered states across
viewport breakpoints, and iterate on specific subcomponents without regenerating
the entire layout from scratch.

Modern versions of v0 support full-stack application logic, integration with
backend databases, GitHub repository synchronization, and direct one-click
deployments to Vercel. Generated code adheres strictly to standard Next.js App
Router conventions, making it straightforward to copy directly into existing
codebases.

## How to use

1. Generate a component in the web workspace: Navigate to `https://v0.app/` and
   enter a prompt specifying the layout, required fields, and styling goals
   (e.g., "Build a pricing table with a monthly/annual toggle and feature
   comparison").
2. Refine visually: Use Design Mode to click on individual elements, adjust
   spacing, customize text content, or regenerate distinct component sections.
3. Import into a local Next.js project via CLI: Add the generated component
   directly into your repository:

```bash
bunx shadcn@latest add "https://v0.app/t/YOUR_SHARE_ID"
```

4. Alternatively, install shadcn dependencies and paste the component:

```bash
bun add lucide-react clsx tailwind-merge
```

```tsx
import { Button } from '@/components/ui/button'
import { Card, CardContent, CardHeader, CardTitle } from '@/components/ui/card'

        <p className="text-3xl font-extrabold">$29/mo</p>
        <Button className="w-full bg-white text-black hover:bg-zinc-200">

    </Card>
  )
```

## When to use it

- Use it when scaffolding landing pages, dashboards, or complex forms where
  starting from a visual preview accelerates developer-designer alignment.
- Use it when you need standard React components that strictly follow the
  shadcn/ui design language and Tailwind CSS conventions.
- Skip it when building in-browser sandboxes with full terminal access; use
  [Bolt.new](../development/bolt-new.md) instead.
- Skip it when you only need curated utility tools and independent dev apps;
  refer to [BuilderTools](../development/buildertools.md).

## Agent notes

- Official URL: `https://v0.app/`.
- Generated code relies on standard shadcn/ui components (`@/components/ui/*`),
  Lucide icons, and Tailwind CSS. Ensure your project has configured path
  aliases in `tsconfig.json` before importing snippets.
- Coding agents can consume shared v0 links directly via `shadcn add <url>`
  without manual DOM scraping.
- Design Mode enables targeted edits, preventing unwanted full-file rewrites
  when modifying minor CSS properties or copy.
