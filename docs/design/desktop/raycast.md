## What it is

Raycast is a desktop launcher that opens apps, searches content, and runs
actions from a keyboard-driven command palette. Its store contains extensions
for developer tools and other services, including browser support checks, color
picking, and editor integrations.

The core launcher is free. Raycast Pro adds cloud sync, custom themes, and AI
features. The official billing manual also lists Pro+, which unlocks additional
AI models, and Max for higher monthly AI credit limits. These are individual
plans; Teams has separate pricing.

Raycast can speed up a developer's desktop workflow, but it is an installed
application rather than a directly callable web-design library or agent service.

## Paywall and pricing

- **Free:** The launcher and extension store are available on the free plan.
- **Paid:** Individual Pro is $10/month or $96/year; Pro+ is $20/month or
  $192/year; Max is $50/month or $480/year. Teams Pro is $15 per user/month or
  $144 per user/year.
- **Sign-up required?** An account is needed for cloud sync, subscriptions, and
  account-linked services. Core local launcher use is available free.
- **Licence for client work:** Raycast is proprietary software. Extension
  authors may set separate licences or service terms for their integrations.

Prices checked 2026-10-07 in the official billing manual. Confirm the live
pricing page before purchasing.

## How to use

1. Install the desktop app from the official Raycast download page for the
   supported operating system.
2. Open the launcher with its configured keyboard shortcut and search for an
   app, file, setting, or action.
3. Browse the extension store for tools used by the project team, such as a
   browser compatibility lookup or editor integration.
4. Add the extension, review the permissions it requests, and test its action
   against a non-sensitive project before relying on it.
5. Use Pro only if the team needs its published sync, theme, or AI features.

## Examples

- [Can I Use extension](https://www.raycast.com/thomaslombart/can-i-use) — check
  browser support for a web feature from the launcher.
- [Color Picker extension](https://www.raycast.com/thomas/color-picker) —
  retrieve colors from the desktop for a design task.
- [Visual Studio Code extension](https://www.raycast.com/thomas/visual-studio-code)
  — open or search editor projects from Raycast.
- [Raycast Store](https://www.raycast.com/store) — browse extensions by category
  and integration.

## When to use it

- Use it when the project team wants keyboard-first access to apps, snippets,
  system actions, and developer extensions.
- Use extension listings to find a small shortcut that saves repeated
  context-switching during design implementation.
- Skip it when the requirement is an API that a coding agent can call or a
  shared web component that must render inside the product.

## Agent notes

- Raycast is a desktop application; no public coding-agent API or MCP server was
  verified for the launcher itself.
- Extension names and features are maintained by individual authors. Review
  permissions, maintenance, and external service terms before use.
- Current individual billing in the official manual: Pro $10/month or $96/year,
  Pro+ $20/month or $192/year, Max $50/month or $480/year.
- Store examples: [Can I Use](https://www.raycast.com/thomaslombart/can-i-use),
  [Color Picker](https://www.raycast.com/thomas/color-picker), and
  [Visual Studio Code](https://www.raycast.com/thomas/visual-studio-code).
