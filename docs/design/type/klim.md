## What it is

Klim Type Foundry is a New Zealand type foundry publishing contemporary type
families. Its site includes specimen pages, family details, licensing, and
examples of the type in use.

Families vary in style and available formats. Select a typeface by testing the
project's real content and checking the needed license: desktop, web, and app
use may be licensed separately. A specimen or evaluation font is not a
production license.

## Paywall and pricing

- **Free:** The catalog and specimens are public. Klim provides test fonts for
  evaluation; these are not a substitute for a production license.
- **Paid:** The FAQ lists a starting price of $60 USD for the first font style.
  Additional styles may be discounted, family packages can reduce the total, and
  license type and usage affect price.
- **Sign-up required?** No account is needed to browse specimens. Purchasing
  requires the foundry's order process.
- **Licence for client work:** Buy the appropriate desktop, web, or app license
  for the actual users and usage. The FAQ describes license terms and seat
  counts; confirm them with the current checkout or foundry.

Prices checked 2026-10-07. The final cost depends on the font and license.

## How to use

1. Browse the catalog and open a specimen page for the candidate family.
2. Paste representative project copy into the specimen. Check headings,
   paragraph texture, numerals, punctuation, and the required glyph set.
3. Identify the formats and font styles needed, plus expected web traffic, app
   distribution, or desktop users.
4. Read the license FAQ and obtain the correct license before shipping the font.
   Record the license scope for the client handoff.
5. Implement the family with the supplied files and CSS instructions, then test
   font loading, fallback metrics, and performance in the target browsers.

## Examples

- [Die Grotesk](https://klim.co.nz/fonts/die-grotesk/) — inspect a contemporary
  sans-serif family and its full specimen.
- [Domaine Display](https://klim.co.nz/fonts/domaine-display/) — compare a
  display serif for editorial or brand headings.
- [Founders Grotesk](https://klim.co.nz/fonts/founders-grotesk/) — evaluate a
  broad grotesk family across styles.
- [Tiempos in use](https://klim.co.nz/in-use/all/tiempos-collection/) — see a
  published family in applied editorial contexts.

## When to use it

- Use it when a project needs a distinctive commercial typeface and has budget
  for a properly scoped license.
- Use specimen pages to check the font against real interface content, not just
  a promotional headline.
- Skip it when the project cannot support the license cost or needs a
  permissively licensed font package instead.

## Agent notes

- Klim is not an npm package. Follow the foundry's delivery and CSS guidance for
  the licensed files.
- Do not commit font files until the client and repository terms allow it.
- Check whether the font has the desired web formats, language coverage, and
  variable-font behavior before implementation.
- Track the purchased styles, seat count, domains, and license category in
  handoff notes; do not infer them from a screenshot.
