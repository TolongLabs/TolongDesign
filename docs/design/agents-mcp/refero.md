## What it is

Refero is a searchable library of extracted website style systems. Style pages
organize colors, typography, spacing, and components into information developers
and coding agents can use.

The library supports browsing and filtering, with DESIGN.md and token-oriented
outputs. Treat entries as researched references and verify details against the
live product before using them in a client brief.

## Paywall and pricing

- **Free:** Public style entries can be browsed without payment.
- **Paid:** Some entries and subscription features require paid access. Current
  prices are shown at checkout rather than on a public pricing page.
- **Sign-up required?:** No account is needed for the public examples below;
  paid access may require an account.
- **Licence for client work:** Refero is proprietary. The reviewed pages do not
  publish a separate license for extracted specifications; do not copy logos or
  protected assets into client work.

Checked 2026-10-07.

## How to use

1. Browse styles by recency or popularity and use available filters to narrow
   the results to a product category or visual direction.

2. Open a style page and inspect its typography, color, spacing, and component
   sections. Check whether DESIGN.md or token export is available to your
   account.

3. Turn useful patterns into a project brief covering hierarchy, type scale,
   surfaces, density, and interaction style. Ask the coding agent to use the
   client’s own assets.

4. Review the implementation at mobile and desktop widths; check contrast and
   component states instead of assuming the extraction is complete.

## When to use it

- Use it when an agent needs a concrete visual system in Markdown or tokens.
- Skip it when you need official brand assets or a component package; use a
  licensed asset source or library.

## Agent notes

Refero documents an MCP connection and agent-readable DESIGN.md. Check the MCP
page for current setup details and limits.

Keep extracted guidance as context and tell the agent which values are
inspiration versus fixed requirements.
