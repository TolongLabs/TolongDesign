## What it is

Lafys is a curated prompt and visual inspiration platform created by designer
Bogdan Falin. It collects high-craft landing pages, fintech marketing layouts,
and WebGL hero sections, pairing each entry with the exact multi-section prompts
needed to recreate it using AI coding agents.

Rather than guessing how to describe complex micro-interactions, dark-mode glass
gradients, or fluid scroll animations to an LLM, builders browse demonstrated
live examples. Each post breaks down the layout into modular sections (e.g.,
Hero, Features, Pricing, Testimonials) and provides tested prompts optimized for
Claude, v0, Lovable, and Cursor.

The platform also includes animated backgrounds, Three.js shaders, and video
previews showcasing how the generated components behave in motion before you
feed the prompts into your agent pipeline.

## How to use

1. Visit `lafys.com` and filter the library by target stack (e.g., v0, Claude,
   Lovable) or component category (Landing Page, WebGL, SaaS).
2. Preview the interactive video demonstration to evaluate typography, spacing,
   and responsive behavior.
3. Click **Copy Prompt** on the chosen section recipe.
4. Paste the prompt directly into your AI coding tool or agent prompt:

```text
Generate a responsive fintech hero section matching this Lafys specification:
- Dark theme with radial subtle glow (#101012 background)
- Two-column layout with split stats counter and floating card previews
- Strict 8px grid spacing, Inter font hierarchy, and Tailwind CSS classes
```

5. Refine the generated JSX output with your brand tokens and real copy.

## When to use it

- Use it when starting a new landing page or marketing site and needing proven,
  structured prompts that yield polished results from generative tools.
- Use it to study how professional design engineers phrase layout, typography,
  and interaction instructions for AI agents.
- Skip it when you already have finished Figma mockups; use Kombai or direct
  Figma-to-code pipelines instead.
