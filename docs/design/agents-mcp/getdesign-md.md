## What it is

getdesign.md is a catalog of more than 550 website design analyses in DESIGN.md
format. Files describe visual patterns such as typography, color, spacing, and
components for coding agents.

The Catalog Pass is a monthly subset of the wider catalog; a private DESIGN.md
can be ordered for one website. These are independent analyses, not official
design systems from the named companies.

## Paywall and pricing

- **Free:** Browse the public catalog and open entries; individual download
  access varies and the pass covers only its selected subset.
- **Paid:** Catalog Pass is $99/month. A private DESIGN.md is currently $39
  one-time, reduced from $59.
- **Sign-up required?:** Browsing is public. Email is required to subscribe or
  request a private DESIGN.md, delivered by email.
- **Licence for client work:** The service is proprietary. Analyses are
  references and do not grant rights to company logos, imagery, copy, or other
  assets.

Checked 2026-10-07.

## How to use

1. Search or page through the catalog for the product category and visual
   character you need. Open an entry and read its independent analysis.

2. Choose a public entry or use the private request form if the source is
   missing; the current private request is $39 one-time.

3. Add the Markdown to project context and ask the agent to use its layout and
   token guidance with the client’s identity and assets.

4. Validate the implementation; one file may not describe every route or
   responsive state.

## When to use it

- Use it when the visual direction is known and an agent needs a portable
  reference.
- Skip it when you need official tokens, source assets, or a full production
  template.

## Agent notes

The output is Markdown intended for coding agents such as Claude Code, Cursor,
Gemini, and ChatGPT.

Do not call an independent analysis an official brand system; avoid protected
assets.
