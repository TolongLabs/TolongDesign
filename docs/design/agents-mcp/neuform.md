## What it is

Neuform is an AI-assisted HTML landing-page builder with a catalog of public
templates. It also describes reusable DESIGN.md files so agents can follow a
page’s style.

Template pages can be inspected and remixed in the hosted editor. Pricing says
browsing is free, while generation uses a limited trial and paid plans; exact
prices were not readable.

## Paywall and pricing

- **Free:** Browse public templates and save account settings. The pricing page
  lists no ongoing free generation allowance.
- **Paid:** Generation begins with a three-day trial that includes 20 prompts;
  Pro, Max, and Ultra tiers follow. Exact prices were not published.
- **Sign-up required?:** Browsing is public. An account is needed to save
  settings or use trial and paid generation.
- **Licence for client work:** Neuform is proprietary. Reviewed pages do not
  state a standalone template license; confirm terms before using templates or
  generated code for clients.

Checked 2026-10-07.

## How to use

1. Browse templates by page type and open one with the right information
   architecture. Inspect the rendered page before remixing.

2. Use the editor to add client content and sections. Use generated DESIGN.md as
   context when asking an agent to continue outside Neuform.

3. Check responsive layouts, remove demo text and images, and inspect exported
   HTML/CSS/JavaScript in the target project.

## When to use it

- Use it when a project needs a remixable HTML starting layout, especially for a
  marketing page.
- Skip it when you need a production React package or a free self-hosted
  generator; use an open registry or build in the project stack.

## Agent notes

DESIGN.md can be placed in the repository and read by an agent; keep source and
product requirements explicit.

Reviewed pages do not advertise a public CLI or MCP integration.
