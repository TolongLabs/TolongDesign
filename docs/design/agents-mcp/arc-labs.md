## What it is

Arc labs is an AI-powered career preparation platform built by developer Vansh
Nagar. It combines a dynamic resume builder with an adaptive mock interview
simulation engine designed specifically for technical roles, full-stack
engineers, and designers.

The interview simulator guides candidates through a structured four-stage
process mirroring real-world tech hiring pipelines: an initial screening round,
a verbal communication interview assessing clarity of thought, an interactive
technical coding round, and a detailed results dashboard analyzing strengths and
blind spots.

Alongside interview simulations, Arc labs provides an in-browser resume builder
featuring a built-in HTML and CSS editor. Users can customize layout templates,
adjust typography, generate content bullet points with AI assistance, and export
print-ready PDFs or shareable web links.

## Paywall and pricing

- **Free (Pro Plan):** $0/month. Includes up to 4 resume projects, 5 AI content
  generations per month, access to basic templates, PDF export, and public
  sharing with an Arc Labs watermark.
- **Paid (Startup Plan):** $9/month. Unlocks unlimited resume projects,
  unlimited AI generations and edits, premium design templates, complete version
  history, private sharing links, removal of watermarks, and viewer analytics.
- **Sign-up required?** Yes, account registration is required to save resume
  projects and record interview simulation history.
- **Licence for client work:** Personal career development tool; resumes and
  exported portfolio materials belong to the user.

## How to use

1. Navigate to `arclabs.space` and click **Get started** to access the
   dashboard.
2. Under **Generate-resume**, select a base layout and enter your professional
   experience. Use the built-in HTML/CSS editor or prompt the AI assistant to
   tailor bullet points to specific job descriptions.
3. Under **Simulate-interview**, choose your target role (Frontend Developer,
   Full-Stack Engineer, or UI/UX Designer) and begin a mock session:
   - Complete the automated screening round questions.
   - Answer verbal situational prompts using audio or text input.
   - Work through technical problem-solving scenarios.
4. Review the generated results breakdown, noting communication scores and
   technical accuracy feedback.
5. Export your finished resume as a PDF or generate a public portfolio link.

## When to use it

- Use it when preparing for developer or design job interviews to rehearse
  technical questions under simulated pressure.
- Use it to scaffold and polish developer resumes using customizable HTML/CSS
  templates.
- Skip it when looking for programmatic coding agents or MCP developer tools;
  Arc labs is a web end-user application.
