## What it is

Icon Museum is a curated archive of mobile app icons. Individual entries
identify an app and may include its category, developer, date, website or App
Store link, designer credit, and a palette extracted from the artwork.

It is a visual reference for studying how app marks use silhouette, contrast,
color, and platform conventions. It is not a production icon library, and the
archive does not publish a reuse licence for the displayed artwork.

## Paywall and pricing

## How to use

1. Browse or search the archive for apps in the same category or with the tone
   you want to study.
2. Open several entries and record the app name, category, designer credit,
   dominant palette, and icon silhouette.
3. Compare the references in a short design brief; describe the visual qualities
   rather than copying a specific mark.
4. Link the reference entries in the brief and create original artwork for the
   TolongLabs project.

There is no documented package install command for this workflow. Use the
official browser or integration route described above, and confirm that any
exported asset is covered by the licence for the intended project.

- [Untitled](https://icon.museum/apps/untitled) — Music app entry with a pale
  purple and dark palette.
- [Rooms](https://icon.museum/apps/rooms) — Games entry showing a brighter
  multi-color palette and developer details.
- [Widgetsmith](https://icon.museum/apps/widgetsmith) — Productivity entry with
  a restrained blue palette.

## When to use it

- Use it during mobile product discovery, moodboarding, or an audit of app icon
  conventions.
- Skip it when you need licensed UI symbols or downloadable assets; use a
  licensed icon library such as Lucide.

## Agent notes

- This is a visual archive, not an API or component package; there is no install
  command.
- Do not treat a visible image as a reusable asset. The rights holders are the
  app creators and designers unless a separate licence says otherwise.
- Capture source links and design observations in the project brief instead of
  copying the artwork.
