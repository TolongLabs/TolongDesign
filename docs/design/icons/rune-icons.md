## What it is

Rune Icons is a browser-based icon set with more than 900 icons on a 24-pixel
grid. The current browser exposes outline, duotone, fill, pixel, and glass
styles, with controls for size, stroke, color, and motion.

The site lets designers preview and export SVG or JSX. Package names for React,
Vue, Svelte, Astro, React Native, Flutter, VS Code, Figma, and MCP are listed as
coming soon, so the browser export is the dependable workflow today.

## How to use

1. Open the icon browser and search by a concrete interface concept, such as
   arrow, home, or search.
2. Compare the same symbol across the five styles before deciding which one fits
   the project.
3. Set size, color, stroke, and motion in the editor, then export the SVG or JSX
   shown by the site.
4. Use the export as a project asset and keep stroke and corner treatment
   consistent across the interface.

There is no documented package install command for this workflow. Use the
official browser or integration route described above, and confirm that any
exported asset is covered by the licence for the intended project.

## When to use it

- Use it when a project needs a distinctive multi-style set and browser- based
  SVG or JSX export.
- Skip it when a stable package-manager integration is required today; use
  Iconoir, Lucide, or Heroicons.

## Agent notes

- The listed package integrations are marked live soon on the official package
  page. Do not assume an npm package is available yet.
- SVG and JSX exports are usable directly by an agent; inspect generated markup
  and add an accessible name only when the icon conveys meaning.
- The official site lists Apache 2.0 and a free-forever offer. Recheck the site
  before relying on package integrations.
