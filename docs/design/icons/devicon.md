## What it is

Devicon collects logos for programming languages, design tools, and development
platforms. The project distributes source SVGs and a font, with original, plain,
line, and wordmark treatments where available.

It is intended for technology stacks, developer profiles, and tool directories
rather than general interface controls. The code and icon font are MIT-
licensed, but the logos represent third-party companies and projects.

## Paywall and pricing

- Free: install the font package, use the public CDN, or reference raw SVGs.
- Paid: no paid plan or price is published.
- Sign-up required? No for the repository or CDN.
- Client work: MIT covers the project assets; follow each brand's own logo rules
  and do not imply endorsement.

Pricing and licence information checked 2026-10-07.

## How to use

1. Browse the official catalog or repository folders for the technology name.
2. Choose the original, plain, line, or wordmark variant that is available for
   that logo.
3. Install the devicon font package and include its stylesheet, or reference a
   specific SVG asset.
4. Use the logo only to identify the technology and keep its proportion and
   brand colors intact.

Install with Bun:

```bash
bun add devicon
```

Minimal usage from the official documentation:

```html
<i class="devicon-devicon-plain" aria-hidden="true"></i>
```

## When to use it

- Use it to label a technology stack, developer portfolio, documentation page,
  or integrations list.
- Skip it for generic UI affordances or when the brand has not permitted the
  intended logo use.

## Agent notes

- Package: devicon. Font classes use the devicon-<name>-<style> pattern.
- The official README also documents CDN and raw SVG usage; avoid loading every
  mark when only a few are needed.
- Logos are third-party trademarks. The README says use should follow each
  brand's policy.
