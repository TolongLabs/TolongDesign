## What it is

Iconsax is the official Vuesax icon library and web app. The current product
advertises 7,000 free icons in six rounded styles, plus more than 44,000 premium
icons and animated assets.

Users can browse, recolor, resize, and export icons from the platform and
official design plugins. Iconsax uses proprietary free and premium licences;
free icons can be used in client products, but distributing templates or UI kits
has attribution requirements.

## Paywall and pricing

- Free: 7,000 icons in six rounded styles with SVG, PNG, and WebP exports.
- Paid: Pro for one user is $9.99 monthly, $39.99 annually, or $199.99 lifetime;
  it unlocks premium icons and tools.
- Sign-up required? The official docs say free icons are available from the web
  app or Figma plugin without registration.
- Client work: free icons may be integrated into commercial work. Digital
  products distributed for sale or reuse require attribution; do not
  redistribute loose files.

Pricing and licence information checked 2026-10-07.

## How to use

1. Search the official icon library by name or category and compare its six
   rounded styles.
2. Customize color, size, and stroke in the web app, then export the selected
   icon as SVG or another offered format.
3. Use the official integration guide or MCP endpoint if an agent needs
   programmatic discovery.
4. Keep free and premium assets separate and include attribution when a
   distributed template or UI kit requires it.

There is no documented package install command for this workflow. Use the
official browser or integration route described above, and confirm that any
exported asset is covered by the licence for the intended project.

## When to use it

- Use it when a product needs a large free set with several rounded styles and
  export formats.
- Skip Pro assets if the project cannot manage seat-based licensing; use Lucide
  or Tabler for open-source alternatives.

## Agent notes

- The V2 licence is proprietary even for the free collection; free does not mean
  open source.
- Pro licensing is per user and subscription rights depend on an active plan or
  a lifetime purchase.
- The docs list an MCP endpoint and browser exports. Do not redistribute loose
  icons; templates and UI kits have separate attribution terms.
