## What it is

CSS.gg is a collection of more than 700 CSS, SVG, and Figma UI icons. Its
repository also describes thousands of glyphs and related design resources, and
the SVG tree contains individual named files.

The licence changed for version 2.1.2 and later. The current terms allow
personal, non-commercial use with attribution, while commercial use requires
explicit written permission; the site does not publish a commercial price.

## Paywall and pricing

- Free: personal, non-commercial use is permitted under the current licence with
  attribution.
- Paid: no commercial plan or price is published. Commercial use requires
  explicit permission.
- Sign-up required? Browsing and copying are available without an account;
  permission is needed for commercial use.
- Client work: do not use current assets in paid or client work until the
  copyright holder grants permission.

Pricing and licence information checked 2026-10-07.

## How to use

1. Browse the official icons page and choose a CSS or SVG version that suits the
   project.
2. Use the repository's SVG files for direct copying, or adapt the site's CSS
   example for a personal prototype.
3. Include attribution as required by the current licence and avoid modifying or
   replicating library functionality.
4. For commercial work, ask the rights holder for written permission and confirm
   the terms before integrating assets.

There is no documented package install command for this workflow. Use the
official browser or integration route described above, and confirm that any
exported asset is covered by the licence for the intended project.

## When to use it

- Use it for personal studies or prototypes where its CSS-first rendering is
  useful.
- Skip it for commercial projects unless written permission is in place; use
  Lucide or Tabler for permissively licensed alternatives.

## Agent notes

- The current licence applies from version 2.1.2. Earlier versions were MIT; do
  not assume that old terms apply to current assets.
- Commercial use needs explicit permission, and the site does not state a fee or
  paid route.
- The README covers CSS, SVG, and Figma assets. Review the current licence
  before copying an asset.
