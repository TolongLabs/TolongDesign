## What it is

make.design is an AI-assisted creation site with tools for website pages,
landing pages, graphics, and image generation. A user starts with a prompt and
can refine the generated output through a chat-style editing workflow.

It is useful for getting from a product description to a visual draft. Treat the
result as a design proposal: check hierarchy, spacing, contrast, copy,
responsive behavior, and asset rights before using it as a client deliverable.

## How to use

1. Write a short brief with audience, goal, content hierarchy, brand direction,
   and any accessibility or technical constraints.
2. Choose a tool such as the website or landing-page generator and submit the
   prompt. Ask for a specific page structure rather than a vague style.
3. Review the draft for content accuracy, readable type, contrast, spacing,
   responsive layout, and the purpose of each interaction.
4. Iterate by requesting one change at a time. Keep the approved structure and
   record decisions that a developer must reproduce.
5. Before a build, turn the chosen result into a brief with screenshots, tokens,
   component states, content, and implementation notes. Do not assume generated
   markup is production-ready.

## When to use it

- Use it when a team needs several visual directions before committing to a
  design system or detailed implementation.
- Use it to explore landing-page hierarchy, then validate the chosen design with
  real content and responsive layouts.
- Skip it when the project requires exact production code, controlled assets, or
  a detailed interactive prototype from the start.

## Agent notes

- No official package, CLI, MCP server, or public API was verified.
- Prompts should include constraints that matter to implementation, such as
  semantic structure, mobile behavior, and keyboard interaction.
- Treat generated text and visuals as drafts. Verify claims and image rights
  before publishing.
- Do not copy generated code into a project without reviewing semantics,
  accessibility, responsiveness, and the target framework's conventions.
