## What it is

Framer combines a visual canvas, responsive website editor, CMS, and hosting. It
lets a designer build a page visually, add interactions, and publish the result
on a Framer subdomain or connected domain.

The Marketplace provides templates, components, and plugins. These are useful as
references or starting points, but review the asset's license and fit before
using it for a client project. Framer's canvas output should be judged as a
hosted site deliverable, not assumed to be a portable source-code base.

## Paywall and pricing

- **Free:** The free plan is available for building and publishing on a Framer
  subdomain, with limits on site features and custom domains.
- **Paid:** The pricing page lists Basic at $10/month and Pro at $30/month on
  annual billing. Enterprise pricing is custom. Monthly billing may differ.
- **Sign-up required?** Yes, to edit, publish, or duplicate a Marketplace item.
- **Licence for client work:** Framer's product is proprietary. Marketplace
  assets may have their own terms; check each item before client use.

Prices checked 2026-10-07. The page may present different prices by billing
cycle or region.

## How to use

1. Start with a blank site or duplicate a template that matches the page
   structure, not merely its colors and imagery.
2. Set the desktop and mobile layouts, then add components for repeated sections
   such as navigation, cards, and calls to action.
3. Use the CMS for repeated content such as articles or case studies. Preview
   responsive behavior and interactions before publishing.
4. Connect a domain and publish through the site settings when the content,
   metadata, and legal pages are ready.
5. For a TolongLabs brief, record the page hierarchy, spacing, breakpoints,
   interaction behavior, and assets to recreate if the project will be
   implemented outside Framer.

## When to use it

- Use it when the deliverable is a hosted marketing site and visual editing is
  more useful than maintaining a custom frontend repository.
- Use a component library and code framework when the site needs custom
  application behavior, data flows, or portability across hosting providers.
- Skip a template if its structure, assets, or license do not fit the project.

## Agent notes

- Official help is available from the site's help center and editor.
- No official MCP server, CLI, or public code-generation package was verified
  for this entry during this review.
- A coding agent can still help turn a Framer reference into an implementation
  brief, but should not assume it can edit the visual project directly.
- Verify the current Marketplace item license before copying assets or
  publishing a derived client site.
