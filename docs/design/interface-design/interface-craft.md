## What it is

Interface Craft is a learning library by interface designer Josh Puckett. The
site describes collections of articles, videos, interactive playgrounds,
examples, and curated references for digital interface work.

The focus is close inspection of craft and implementation details rather than a
component package. The public site and updates page reveal the library's format,
but individual member lessons are gated. Public sample chapters could not be
verified during this review.

## Paywall and pricing

- **Free:** The public homepage and updates page can be read without a
  membership. The full lesson library is presented as member content.
- **Paid:** Lifetime membership is offered for a one-time $199 payment. The page
  also displays $249 as a crossed-out price.
- **Sign-up required?** Yes, membership is needed to access the paid library.
- **Licence for client work:** This is educational content, not a commercial
  asset library. A license for reusing lesson materials in client work was not
  published on the public pages reviewed.

Pricing checked 2026-10-07. Confirm the displayed checkout terms before
purchase.

## How to use

1. Read the public overview and updates to understand the available lesson
   formats and current scope.
2. Choose a topic related to a live design problem, such as interaction
   feedback, interface layout, or micro-details.
3. Work through a lesson and note the decision it demonstrates, the user
   context, and any implementation constraints.
4. Translate observations into a project-specific brief. Avoid copying a visual
   treatment without checking the product's brand and accessibility needs.
5. If sharing notes with a coding agent, provide your own summary and the
   relevant constraints rather than assuming the agent has membership access.

## When to use it

- Use it when the team wants structured study of interaction and interface
  details and can apply those ideas to its own product.
- Pair lessons with a real design review so the work addresses actual user needs
  rather than polish in isolation.
- Skip it when the immediate need is a ready-to-install component library or a
  free reference gallery.

## Agent notes

- No public API, MCP server, downloadable code package, or agent-specific
  documentation was verified.
- Membership-gated lessons may not be accessible to an agent without an
  authorized account.
- Treat the creator's public experiments as inspiration, not as a license to
  reproduce their assets or code.
- A useful handoff is a concise note naming the observed pattern, state
  transitions, keyboard behavior, and project-specific acceptance criteria.
