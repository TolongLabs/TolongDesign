## What it is

Figma is a collaborative interface design tool for creating vector-based
layouts, prototypes, and shared design systems. Its product family includes
Figma Design, FigJam, Dev Mode, and newer creation and publishing tools.

Teams can work in the same file, reuse components and styles, and connect a
prototype to a flow. Dev Mode presents measurements, assets, and code-oriented
details to developers. A design file is still a source of decisions, not a
finished implementation or guarantee of accessible production code.

## Paywall and pricing

- **Free:** Starter includes personal drafts and collaboration features with
  limits on team files and advanced controls.
- **Paid:** The pricing page lists Professional seats at $16/month for full
  access, $12/month for Dev Mode, and $3/month for collaboration. Higher team
  plans have different seat prices and billing terms.
- **Sign-up required?** Yes, to create files, collaborate, and duplicate most
  Community resources. Public customer stories can be read without an account.
- **Licence for client work:** Figma is proprietary software. Client work may be
  created in it; confirm account and asset terms for the team's plan and each
  Community resource.

Pricing checked 2026-10-07; the pricing page may change by region and billing
period.

## How to use

1. Create a team file and set the viewport and core pages for the product.
2. Build a small set of reusable components, text styles, and color variables
   before laying out every screen.
3. Link the key screens into a prototype. Test navigation and states with the
   product team before implementation.
4. Use Dev Mode to inspect spacing, assets, and component intent. Record any
   behavior that is not obvious from the static frame.
5. For coding agents, connect the official Figma MCP integration and provide the
   specific file or node to inspect. Ask for measurements and structure; review
   generated code against the design and project conventions.

## When to use it

- Use it when designers, product owners, and developers need a shared source for
  screens, reusable components, and interaction decisions.
- Use a design token or code repository as the implementation source of truth
  when production behavior must stay synchronized with code.
- Skip it for a quick CSS sketch where there is no collaboration or handoff
  need; a browser prototype may be faster.

## Agent notes

- Official documentation: [Figma Help](https://help.figma.com/).
- Figma's MCP server can provide files and design context to supported coding
  clients; access depends on account, plan, and configuration.
- The official UI kits guide explains how to start from system resources.
- Do not assume a screenshot describes component behavior, responsive rules,
  accessibility, or the intended source of truth.
- Check licenses for fonts, icons, and Community files separately from the Figma
  software subscription.
