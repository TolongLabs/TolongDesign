## What it is

Lab01 is a design studio site featuring a collection of interface experiments.
The experiments include small, polished web interactions and demonstrations; the
site also presents studio services and selected work.

Treat each page as a reference for composition and behavior. The site lists font
and color information for some experiments, but that does not grant rights to
copy the assets or reproduce the design. Custom studio engagements are
separately priced.

## Paywall and pricing

- **Free:** The public experiment pages can be viewed without payment.
- **Paid:** The studio homepage lists custom work starting at $10,000. This is a
  services starting point, not a fee for browsing the gallery.
- **Sign-up required?** No account was required to view the public experiments.
- **Licence for client work:** The experiments are not presented as open-source
  assets. No general reuse license was published; use them as visual reference
  and obtain permission before copying assets or code.

Pricing and access checked 2026-10-07.

## How to use

1. Browse the experiment index and open a page with a relevant layout,
   component, or motion treatment.
2. Inspect the experience at desktop and narrow viewport sizes. Note the
   hierarchy, type scale, palette, interaction trigger, and feedback.
3. Save the URL and write down the design principle that is useful, rather than
   copying the complete visual treatment.
4. Turn the findings into a brief for a TolongLabs project: content, states,
   constraints, and a reference screenshot or link.
5. Verify licenses for typefaces and other assets independently before including
   them in a client project.

## When to use it

- Use it when a designer needs a concrete reference for visual polish or a
  focused interaction before writing a UI brief.
- Use it alongside usability and accessibility requirements; a polished demo
  does not prove a pattern is right for the product.
- Skip it when the need is a licensed component package or a documented
  implementation with maintenance guarantees.

## Agent notes

- No package, CLI, MCP service, or public source repository was verified.
- The pages can inform a design description, but do not assume the source or
  assets can be copied.
- If a page lists a font or color, verify the font's license at its foundry
  before using it in production.
- Provide agents with the reference URL and the specific behavior to study; ask
  them to create a project-native implementation rather than clone assets.
