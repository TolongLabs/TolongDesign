## What it is

UIWTF is a collection of experimental web interface ideas. Its main page links
to patterns such as command menus, link previews, component menus, quick links,
minimaps, and browser-history controls.

Individual pages are useful for seeing a pattern in a working browser context.
The source-copy control can help inspect an implementation, but the site does
not present itself as a versioned package or guarantee that copied code is
maintained, accessible, or licensed for reuse.

## How to use

1. Browse the homepage links and pick a pattern related to a real user task.
2. Open the specific demo and test it with pointer and keyboard input. Record
   how it opens, responds, and closes.
3. Use “Copy Source” only to inspect the page's implementation. Check the code
   and license rather than treating it as a supported dependency.
4. Write a design note describing the interaction, state changes, keyboard path,
   and failure cases before adapting it to the project's stack.
5. Rebuild the pattern in the site's design system and test it with assistive
   technology and reduced-motion settings.

## When to use it

- Use it when a team wants to explore an unusual interaction or find a fresh
  reference for a compact web control.
- Use a maintained component library for production controls where keyboard and
  accessibility behavior must be dependable.
- Skip a pattern if it makes a familiar task harder to discover or use.
