# ICQR Magic Tree reference notes

Checked 2026-10-11. [The full study](./tree-icqr-study.md) is the canonical
method, evidence manifest, worker outcome, and limitations record.

## Identity

[tree.icqr.com](https://tree.icqr.com/) publishes the title “ICQR Magic Tree —
3D QR Code Generator.” Its description presents link-to-tree generation,
season/color customization, and sharing. Author metadata names ICQR, not an
identified individual. No source or asset-reuse licence was verified.

## Evidence stages

The Luna reference worker initially inspected static HTML. It found metadata but
no readable application body and correctly reported no visual/runtime
observations. The main agent subsequently used REA 6.4.0 to collect and inspect
actual screenshots and accessibility inventories in a separate browser profile.

Desktop 1440 × 900 and portrait-mobile 390 × 844 captures show the brand,
URL/share/season/audio controls, a credits button, and an otherwise spacious
canvas-led layout. The smaller 780 × 493 landscape viewport shows an explicit
unsupported-size message. The headless browser reported WebGL unavailable; its
blank canvas does not verify the intended tree appearance or animation.

## Reference boundary

Use observed hierarchy and responsive control placement as inspiration for
original work. Keep product metadata separate from verified behavior. Full 3D,
successful QR generation/scanning, seasonal transitions, audio, sharing,
keyboard navigation, reduced motion, and performance remain unverified.
