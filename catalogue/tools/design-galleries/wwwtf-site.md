## What it is

wwwtf.site is an eccentric design and creative coding gallery documenting the
unfiltered, experimental side of the modern web. Built and curated by designer
Ali (aaali.xyz), the archive indexes web projects characterized by surreal
storytelling, complex canvas interactions, playful audio engines, and boundary-
pushing visual effects.

Where mainstream design resources cater to conversion-optimized SaaS funnels,
wwwtf.site showcases pure digital play. The featured entries range from
interactive 3D physics playgrounds and glitch art portfolio experiments to
satirical web toys and retro computing simulations.

Each entry provides direct links to the live experience along with contextual
notes, offering developers and design engineers a catalogue of what is
technically achievable when browser constraints are pushed to their limits.

## How to use

1. Navigate to `https://wwwtf.site/` to explore the latest curated experimental
   sites.
2. Select any card to view the featured preview and open the live URL in a
   WebGL-capable browser.
3. Open DevTools on the target experience to analyze the underlying technical
   architecture (such as Three.js, Canvas 2D, Web Audio API, or custom GLSL
   fragment shaders).
4. Adapt creative interaction patterns—such as playful hover triggers, physics
   drop zones, or easter eggs—into client brand experiences to add character.

## When to use it

- Use it when designing promotional campaigns, creative studio sites, music
  experiences, or gamified landing pages.
- Use it when looking for inspiration for bespoke easter eggs, interactive 404
  pages, or interactive celebratory states.
- Skip it when designing structured enterprise dashboards, data tables, or
  conversion-focused ecommerce checkouts; refer to
  [SaaS Landing Page](../design-galleries/saas-landing-page.md) or
  [Sections.wtf](../design-galleries/sections-wtf.md) instead.

## Agent notes

- Built with Framer with no programmatic API or machine endpoints.
- Useful for coding agents when recommending creative interaction ideas or
  advising developers on playful easter egg mechanics.
- Experiences cataloged frequently require hardware acceleration and desktop
  pointing devices to appreciate full interactivity.
