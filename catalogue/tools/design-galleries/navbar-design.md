## What it is

Navbar Design indexes website navigation patterns by type and visual style. The
homepage reports 29 navbar examples across nine styles and seven types,
including dropdown, full-screen, mega, mobile, side-drawer, static, and sticky.

Each record includes a short editorial note, tags, and a link to the real
website. It is a focused reference gallery, not a component library or code
download.

## Paywall and pricing

## How to use

1. Browse all entries, or choose a type such as Mobile, Dropdown, Sticky, or
   Full Screen.

2. Use style tags such as Animated, Minimalism, Retro, or Typographic to find a
   visual direction compatible with the brief.

3. Open a record and follow Visit Website. Test the live navigation with
   keyboard, pointer, and mobile viewport to understand behavior.

4. Write a design brief that identifies information architecture, trigger
   behavior, responsive changes, and accessibility needs. Rebuild the behavior
   for the client’s own content.

## When to use it

- Use it when the main design question is how to organize and present site
  navigation.
- Skip it for general page layouts; use
  [Curated Design](../design-galleries/curated-design.md). For footer
  references, use [footer.design](../design-galleries/footer-design.md).
