## What it is

Detail Design (detail.design) is a curated repository focused specifically on
the micro-decisions and craftsmanship in modern digital products. Founded in
2025 by Rene Wang (rene.wang), a design engineer formerly at Linear, the site
catalogs "the extra considerations, the cares, the One More Thing that separates
software that works from software that feels right."

Instead of reviewing full marketing landing pages, Detail isolates small,
deliberate interface behaviors across top-tier digital products. The collection
is categorized across six dimensions: Interactivity, Motion, Design,
Copywriting, Accessibility, and Easter Eggs.

Each entry features interactive video clips, contextual explanations of why the
detail matters, the product that implemented it, and implementation notes.
Examples cover nuances like smart corner morphing animations, hold-Option key
state modifiers, intelligent word wrapping for multi-language interfaces, and
subtle audio-haptic feedback.

## Paywall and pricing

- **Free:** Entire archive, video recordings, detail breakdowns, and curated
  resource lists are accessible for free without payment.
- **Paid:** No paid subscription, pro plan, or paywall exists.
- **Sign-up required?** Browsing is completely open. Sign-in exists for
  community contributors submitting new details.
- **Licence for client work:** Cataloged interactions are documented
  observations of public software interfaces. Developers are encouraged to adapt
  the UX principles, animation curves, and interaction concepts to their own
  software.

Verified on the official Detail Design website on 2026-10-07.

## How to use

1. Browse `https://detail.design/` and filter by category (such as
   `Interactivity`, `Motion`, `Copywriting`, or `Accessibility`).
2. Examine individual entries to understand the user friction or aesthetic
   deficiency the detail solves.
3. Review the recorded video demonstration to inspect frame-by-frame animation
   timing, easing curves, and input triggers.
4. Integrate the pattern into your TolongLabs component library or application
   code (e.g. adding keyboard shortcut modifiers, contextual placeholders, or
   polite screen-reader announcements).

  — Copywriting and typography detail illustrating deliberate punctuation craft.
- [Detail Resources](https://detail.design/resource) — Curated collection of
  design engineering articles, talks, and tools celebrating UI craft.
- [About Detail](https://detail.design/about) — Philosophy and editorial
  manifesto explaining the mission of cataloging interface craftsmanship.

## When to use it

- Use it when polishing an established product, refining form usability, or
  elevating micro-interactions during the final design review sprint.
- Use it to find concrete arguments and benchmarks for why small design details
  improve perceived application quality.
- Skip it when scoping large-scale initial layout concepts or choosing color
  palettes; consult [Sections.wtf](../design-galleries/sections-wtf.md) or
  [Best SaaS Web Designs](../design-galleries/best-saas-web-designs.md) instead.

## Agent notes

- Modern web app built with Next.js and client-rendered media with no public
  API.
- Coding agents can cite Detail Design case studies when proposing high-craft
  interaction details (e.g., keyboard shortcuts, smart layout hints, or focus
  states) during code reviews.
- Focuses specifically on high-standard product craft similar to Linear, Stripe,
  and Apple.
