## What it is

Best Website Gallery (often abbreviated as BWG) is an independent, hand-curated
web design showcase founded in 2008 by German digital designer and front-end
developer David Hellmann. Originally started as a personal bookmark archive to
track inspiring digital work, it has grown into one of the longest-running
galleries in the design community.

The platform contains a selective archive of over 2,000 hand-picked websites.
Each listing includes full-viewport screenshots, high-level technical tags (such
as CMS, frontend frameworks, and animation libraries), color palette breakdowns,
and direct links to live productions.

Unlike platforms monetized via pay-to-submit models or community voting
contests, BWG remains an author-curated project. Entries are vetted based on
technical polish, typography balance, creative art direction, and overall
execution quality, making it a dependable source of inspiration free from
commercial bias.

## Paywall and pricing

- **Free:** Browsing the entire archive and exploring category and tech tags are
  100% free.
- **Paid:** No paid subscription plans, listing fees, or expedited review
  charges.
- **Sign-up required?** No. All archives and search filters are accessible
  publicly without creating an account.
- **Licence for client work:** Displayed websites are the copyrighted work of
  their respective agencies, designers, and clients. They are indexed as design
  references and conceptual inspiration.

## How to use

1. Browse by tech stack or category: Use the filter navigation to locate sites
   built with specific tools (e.g., Webflow, WordPress, custom React builds) or
   tailored to particular industries (agencies, portfolios, e-commerce).
2. Inspect color and typographic cues: Review the color palettes and font
   choices highlighted in each entry detail page.
3. Open live links for interaction review: Visit the live URLs to test scroll
   performance, responsive viewport breakpoints, and navigation patterns on real
   devices.
4. Document visual references: Link specific BWG entries in project RFCs or
   moodboards to align stakeholders on aesthetic fidelity.

## When to use it

- Use it when looking for tasteful digital agency portfolios, studio homepages,
  or bespoke editorial web projects.
- Use it to study real-world implementations tagged by underlying CMS and tech
  stack.
- Skip it when you need rapid copy-paste Tailwind components or ready-to-use
  code blocks; refer to [Landingfolio](../design-galleries/landingfolio.md)
  instead.

## Agent notes

- Visual gallery without a public REST API, npm package, or CLI tool.
- Entries provide valuable human-curated metadata (CMS, technology, color
  palette tags).
- Agents can reference BWG links to help engineering teams establish aesthetic
  benchmarks for bespoke web builds.
