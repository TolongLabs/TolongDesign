## What it is

Curated is a handpicked index of live sites, including portfolios, agency sites,
product pages, and landing pages. Each site record includes a short description,
category and style tags, and a link to the live website.

Its Sections area separates page elements such as heroes, pricing, FAQs, and
footers. Basic website browsing is free; Pro unlocks the full section library
and advanced saving and filtering. A template store is also linked from the
gallery.

## Paywall and pricing

- **Free** The full website collection and a sample of each section type are
  available for free. Basic browsing does not require a subscription.
- **Paid** Curated Pro is $9/month, billed monthly, and includes a 7-day free
  trial. It unlocks all sections, unlimited bookmarks, advanced filters, and CSV
  export. Some store templates are sold separately.
- **Sign-up required?** An account is needed to bookmark or start the Pro trial.
  Browsing the website gallery is public.
- **Licence for client work** The gallery links to live sites; screenshots and
  third-party page content are not licensed for reuse. Template products have
  their own terms.

Pricing and availability checked 2026-10-07.

## How to use

1. Use Browse to search by a company, category, or style. Start with the broad
   Website collection when the brief is still open.

2. For a specific page problem, use Sections and select a type such as Hero,
   Pricing, FAQ, or Footer. Combine category and visual-style filters to narrow
   the sample.

3. Open each site record to read its tags and jump to the live source. Compare
   structure, hierarchy, copy density, and imagery rather than tracing the
   screenshot.

4. Write a short design brief with the target audience, page section, visual
   traits, and source links. Treat any template in the Store as a separate
   purchase and license.

## When to use it

- Use it when you want live-site references organized by industry, visual style,
  or page section.
- Skip it for detailed mobile flows; use
  [Mobbin](../design-galleries/mobbin.md). For SaaS-only examples, use
  [Saaspo](../design-galleries/saaspo.md).
