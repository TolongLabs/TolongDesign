## What it is

Inspora is an archive of contemporary visual work across web design, branding,
product, motion, illustration, 3D and print. Its feed separates recent work from
featured selections and lets visitors narrow the collection by discipline.

Individual posts pair a visual with creator attribution and descriptive labels
such as industry, palette and style. The record links back to the original
creator post, so the archive is useful for discovery and comparison rather than
as a source of reusable assets.

## How to use

1. Open the archive and choose a discipline such as Web, Branding, Product or
   Motion.
2. Use Latest or Featured to choose between recent additions and editor-selected
   work.
3. Open a post and note its industry, palette, visual style and the linked
   original source.
4. Compare several references that solve a similar audience or product problem.
5. Save the source URLs in the project brief; do not copy a creator’s artwork
   into a deliverable.

**Capture in a TolongLabs design brief:**

- Describe the audience and page purpose before selecting a reference.
- Record the palette, typography scale, layout rhythm and interaction cues
  separately.
- State which qualities are inspiration and which implementation details must
  differ.

  Branding reference built around large typography and abstract digital
  patterns.

## When to use it

- Use it when a project needs a visual starting point across more than
  landing-page layouts.
- Skip it when you need implementation-ready components or verified licensing;
  use a component library in this repo instead.

## Agent notes

The archive is a human-facing visual catalogue. No public API, CLI, llms.txt or
code package was found in the pages checked.

Treat creator images as references; follow the original link for attribution and
rights details before any reuse.
