## What it is

Details curates high-quality website references by page type and interaction,
including navigation, scroll animation, transitions, buttons, and content
sections. Inspo is the searchable reference library; the Vault contains
implementation-ready interactions and sections.

Its official pages offer a live MCP connection for AI tools. The paid Max plan
adds Vault access, code snippets, implementation notes, and AI-ready prompts,
while Starter provides a smaller free sample.

## Paywall and pricing

- **Free** Starter lets users browse recent Inspo entries, category previews,
  and selected free resources. A free account is available.
- **Paid** Pro is listed at $9/month on the current pricing page. Max is
  $19/month and Team is $22/seat/month on annual billing. A $490 lifetime tier
  is listed as sold out.
- **Sign-up required?** An account is needed to save references or use the
  library. Full Inspo, Vault, and MCP access require a paid plan.
- **Licence for client work** The Vault FAQ allows use in client websites,
  agency work, and commercial products; it prohibits reselling or republishing
  the resources as a competing library.

Pricing and availability checked 2026-10-07.

## How to use

1. Search Inspo with a phrase describing the page need, such as “playful
   services section,” or filter by a page type such as Hero, Footer, or
   Navigation.

2. Open an entry to inspect the original live site and the selected interaction.
   Save it to a board with a note describing the user goal and motion cue.

3. When implementation help is needed, search the Vault for a matching section
   or interaction and read its implementation notes before copying code.

4. For an AI workflow, connect Details MCP from the account and ask the agent
   for a few references plus the design qualities that make them work.

  hospitality example with content and navigation patterns.
- [Griflan](https://www.details.so/inspo/site/griflan-com) — A studio site with
  carousel and testimonial references.

## When to use it

- Use it when a team needs website-specific interaction references or code that
  can be adapted to a real stack.
- Skip it for mobile app screen flows; use
  [Mobbin](../design-galleries/mobbin.md). For community concepts, use
  [Layers](../design-galleries/layers.md).

## Agent notes

- Official MCP is linked from the Details site and pricing page. The Max plan
  includes MCP access to both Inspo and Vault; Pro includes Inspo access.
- Vault resources use plain HTML, CSS, and JavaScript and can be adapted to
  modern stacks. Check per-resource notes for routing or framework requirements.

## Alternatives in this repo

- [Mobbin](../design-galleries/mobbin.md) — Real mobile and web app screens with
