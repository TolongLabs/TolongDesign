## What it is

DesEngs describes itself as a resource for design engineers, curated by people
working in that area. The directory collects material to read, watch, listen to,
browse, use, build with, learn from, join and follow.

Entries include a title, a short description and a destination link. It is
broader than a visual gallery: the catalogue mixes tools, articles, videos,
communities and other learning resources.

## Paywall and pricing

## How to use

1. Use the category controls to choose a mode such as Read, Watch, Use or Build.
2. Search for a topic or scan the resource cards and their summaries.
3. Open the original destination and confirm its current scope, licence and
   framework support.
4. Keep a short list of resources that fit the project’s actual stack and
   delivery constraints.
5. Turn selected references into a build brief with implementation and
   accessibility notes.

**Capture in a TolongLabs design brief:**

- Record the resource type and the problem it could help solve.
- For code resources, verify maintenance, framework and licence at the
  destination.
- Separate learning material from dependencies that may enter production.

## Examples

- [loading.dev](https://loading.dev) React loading indicators and patterns for a
  waiting state.
- [Gradientool](https://gradientool.com) A generator for exploring varied
  gradient outputs.
- [Use Layouts](https://uselayouts.com) A collection of React components
  described as using Framer Motion and Tailwind.

## When to use it

- Use it when a design engineer needs a starting list spanning tools, learning
  and implementation resources.
- Skip it when you need only visual site captures; use Inspora or Landing Love.
