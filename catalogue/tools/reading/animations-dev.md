## What it is

Animations.dev is an interactive learning platform and comprehensive course on
web animation created by Emil Kowalski (design engineer at Linear, previously at
Vercel, and author of popular open-source packages like Sonner and Vaul). Over
13,000 designers and frontend engineers have enrolled in the course.

The course is built around the thesis that what separates a good interface from
a great one is how it _feels_. Instead of merely teaching API syntax, Emil
teaches the underlying theory of motion:

- **Animation Theory:** Easing curves, timing, spring physics (stiffness,
  damping, mass), perceptual duration, orchestration, and understanding when
  _not_ to animate.
- **CSS Animations:** Deep mastery of native CSS transitions, keyframes,
  composited transforms, and performant hardware-accelerated rendering.
- **Motion (Framer Motion):** Building complex, production-grade interactive
  React components—such as layout animations, animated feedback popovers,
  dynamic height transitions, and interactive drawers.
- **Production Walkthroughs:** Full real-world breakdowns including the Family
  iOS drawer, Apple Dynamic Island springs, fluid navigation bars, and SVG
  micro-interactions.

The platform provides a custom-built interactive sandbox where students "touch"
and tweak animations, compare good vs. bad easing side-by-side, and complete
hands-on coding exercises.

## How to use

1. Master easing and spring parameters: Study the Animation Theory module to
   understand how mass, stiffness, and damping interact, eliminating guesswork
   when configuring Framer Motion springs.
2. Implement auto-height transitions: Use the documented techniques combining
   `useMeasure` and Framer Motion to smoothly animate modal expansions and
   accordion collapses without jarring layout jumps.
3. Leverage included AI agent skills: Use the 15 tailored AI skills provided
   with the course to audit animation code in existing repositories, identify
   jitter or excessive durations, and generate targeted animation fixes.
4. Apply custom easing curves: Incorporate Emil's curated easing presets into
   project Tailwind or CSS custom property tokens.

## When to use it

- Use it when elevating React applications with tactile, natural animations that
  match the quality of Linear, Apple, or Vercel interfaces.
- Use it to train frontend developers on the principles of motion design and
  spring physics.
- Skip it if you only need static, non-animated web pages or pure documentation
  sites; consult [Smashing Magazine](../reading/smashing-magazine.md) instead.
