## What it is

Codrops is an influential creative frontend development and web design blog
founded by Manoela Ilic and Pedro Botelho. Published under the Tympanus domain
since 2009, it has served as the premier showcase for experimental web UI,
pushing the technological boundaries of browser animation and visual
storytelling.

The publication is structured into three main pillars:

1. **Tutorials:** Detailed, step-by-step technical guides breaking down how to
   build sophisticated visual effects—such as interactive hover distortions,
   magnetic buttons, canvas particle systems, and dynamic 3D typography.
2. **Playground:** A collection of highly experimental interactive prototypes,
   page transitions, menus, and layout explorations created in collaboration
   with international creative developers and digital agencies.
3. **CSS Reference:** An extensive, beginner-friendly dictionary and reference
   manual for CSS properties with interactive live examples.

Every experiment and tutorial published on Codrops includes a live interactive
demo and a public GitHub repository with full source code licensed under MIT,
making it directly useful for production engineers looking to adapt techniques.

## Paywall and pricing

- **Free:** 100% of the content on Codrops—including all articles, tutorials,
  interactive playground demos, downloadable source archives, and CSS
  references—is completely free to access.
- **Paid:** None. Codrops does not charge for subscriptions, memberships, or pro
  tiers. The platform is supported by community sponsors and display ads.
- **Sign-up required?** No sign-up or authentication is required to read
  articles, test live demos, or download source code from GitHub.
- **Licence for client work:** Demos and tutorial source code hosted in the
  Codrops GitHub organization are released under the permissive MIT license,
  allowing developers to freely use, modify, and integrate code into commercial
  client projects with proper attribution.

## How to use

1. Browse experimental interaction patterns: Review the Codrops Playground
   (`https://tympanus.net/codrops/category/playground/`) when exploring creative
   concepts for client landing pages, hero headers, or interactive portfolios.
2. Study the underlying architecture: Read corresponding tutorials to learn how
   complex effects combine standard HTML DOM elements with Three.js WebGL
   canvases and GSAP ScrollTrigger timelines.
3. Clone and customize source code: Grab the MIT-licensed code from the GitHub
   repository linked in the tutorial header, adapt the shaders or CSS
   transitions, and integrate them into the project.
4. Consult the CSS Reference: Use `https://tympanus.net/codrops/css_reference/`
   to clarify syntax, edge cases, and visual behavior of specific CSS rules.

## When to use it

- Use it when designing bespoke award-winning agency websites, high-end luxury
  showcases, or interactive landing pages requiring unique micro-interactions.
- Use it to study how seasoned creative technologists write custom WebGL shaders
  and coordinate performant animation loops.
- Skip it when building conventional administrative dashboards or standard B2B
  SaaS data tables; consult [Smashing Magazine](../reading/smashing-magazine.md)
  or [Laws of UX](../reading/laws-of-ux.md) instead.

## Agent notes

- Agent-friendly: Every demo links to an open-source GitHub repository under
  `github.com/codrops`, making full source code, GLSL shader code, and animation
  timelines easy to clone and inspect.
- Code patterns frequently leverage modern Three.js, GSAP (GreenSock), Lenis
  smooth scroll, and modern CSS transforms.
- Remember to review performance and mobile fallbacks when adapting Codrops
  demos, as heavy WebGL scenes can impact battery life and low-powered mobile
  devices.
