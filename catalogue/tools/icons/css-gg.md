## What it is

CSS.gg is a browser collection of 700+ CSS, SVG, and Figma UI icons. The live
site showed 704 icons, including 8 animated entries, and links to Patterns,
Colors, Layouts, Figma, and the public GitHub repository. Its repository also
describes thousands of glyphs and related design resources.

The license changed for version 2.1.2 and later. Current terms allow personal,
non-commercial use with attribution; commercial use requires explicit
permission. The site links to a Pro page, but the route says “Coming Soon” and
does not publish a price or commercial license fee.

## Paywall and pricing

- **Free:** Personal, non-commercial use is permitted under the current license
  with attribution. Browsing the icon library does not require an account.
- **Paid:** The Pro route says “Coming Soon”; no plan or price is published.
  Commercial use requires explicit permission, with any fee not stated.
- **Sign-up required?** No account is needed to browse the icons. The Pro page
  invites visitors to join a notification list.
- Client work: do not use current assets in paid or client work until the
  copyright holder grants permission.

Pricing and licence information checked 2026-10-07.

## How to use

1. Browse [Symbols](https://css.gg/icons) or filter the collection by rounded,
   squared, CSS, or animated icons.
2. Open an icon page and choose an available format such as CSS, SVG, Figma,
   PNG, or TSX.
3. For personal, non-commercial use, retain the required attribution and do not
   create derivative works or copy the library's functionality.
4. For commercial or client work, obtain explicit written permission before
   integrating an asset; the site does not publish a fee.

There is no documented package install command for this workflow. Use the
official browser or integration route described above, and confirm that any
exported asset is covered by the licence for the intended project.

## When to use it

- Use it for personal studies or prototypes where its CSS-first rendering is
  useful.
- Skip it for commercial projects unless written permission is in place; use
  Lucide or Tabler for permissively licensed alternatives.
