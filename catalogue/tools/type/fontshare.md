## What it is

Fontshare is a font discovery and distribution platform from Indian Type
Foundry. It presents type families with specimen pages and pairing suggestions.
The homepage displayed a catalog of 100 fonts and 59 pairings when checked.

Fontshare's About page says its fonts can be used for personal and commercial
projects. Each family has its own license details; the ITF Free Font License
allows broad use but restricts modification, conversion, subsetting, and
redistribution of the font files. Read the family license before embedding or
handing font files to a client or contractor.

## Paywall and pricing

- **Free:** The About page states that Fontshare fonts are free for personal and
  commercial use. Families can be browsed and downloaded from the site.
- **Paid:** No paid tier was published for the Fontshare catalog reviewed.
- **Sign-up required?** Browsing is public. The reviewed pages did not require
  an account to inspect families; follow the current download flow for any
  account prompt.
- **Licence for client work:** Commercial use is stated, but license details
  vary by family. The ITF Free Font License does not allow modifying or
  redistributing the font files. Verify the exact family license.

Access and license pages checked 2026-10-07.

## How to use

1. Browse the catalog by style or use the search field to find candidate
   families. Open the specimen rather than selecting from a thumbnail alone.
2. Test the actual project copy in headings, body text, numerals, and UI labels.
   Check available weights and any variable axes.
3. Compare suggested pairings, then verify that the chosen fonts support the
   languages and glyphs required by the site.
4. Read the license linked from each family page. Download only from the
   official source and note the family, version, and license in the project.
5. Test rendering on the target browsers and decide whether to self-host or use
   another permitted delivery method.

- [General Sans search](https://www.fontshare.com/?q=General+Sans) — locate a

- [Fontshare About](https://fontshare.com/about) — review the platform's
  commercial-use statement before choosing a family.

## When to use it

- Use it to shortlist fonts for a client or product site when a free
  commercial-use option is appropriate.
- Check the actual family license, language coverage, and delivery terms before
  adding files to a production repository.
- Skip it when the project needs a font with a particular enterprise license,
  extended language coverage, or a foundry support agreement not offered by the
  selected family.

## Agent notes

- There is no package install command; download or link the chosen family
  according to its license and the project's asset policy.
- Do not assume every family has the same license or that free use means
  modification and file redistribution are permitted.
- Do not commit font binaries to this reference repository. In a project, follow
  the client agreement and repository asset rules.
- Record the family name and exact license so a developer can verify the
  implementation and handoff.
