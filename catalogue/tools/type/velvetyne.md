## What it is

Velvetyne Type Foundry distributes experimental typefaces and publishes
specimens and project information. The collection includes unconventional
display styles alongside more practical text families.

The fonts are freely downloadable, but the exact license is specific to each
family. The foundry's general download information describes rights to use,
modify, and redistribute with conditions such as attribution and share-alike;
check the linked license for the individual font before shipping it.

## Paywall and pricing

- **Free:** Public fonts can be downloaded. The site accepts support for the
  foundry, but no paid-only tier was found.
- **Paid:** Not published as a requirement for use.
- **Sign-up required?** No account requirement was shown for viewing the catalog
  or downloading public files.
- **Licence for client work:** Commercial use is allowed by the applicable open
  font license, subject to its conditions. Attribution and share-alike terms may
  apply; confirm the license of each family.

Access and license information checked 2026-10-07.

## How to use

1. Browse the catalog and open the specimen for a candidate family. Test the
   typeface with the actual words and visual context of the project.
2. Download the font from its official page and read the associated license file
   before adding it to a client repository.
3. Check available styles, glyph coverage, and browser formats. Decide how the
   font will be served and whether attribution is required.
4. Add the font to the project's typography tokens and verify rendering at
   multiple sizes, browsers, and language samples.
5. Preserve the license text and attribution with the project assets where
   required, and share modified font files under the required terms.

## When to use it

- Use it when a brand or editorial project calls for a distinctive display face
  and the team can comply with the selected license.
- Test expressive fonts in context; a typeface that works in a specimen may be
  unsuitable for long passages or small interface text.
- Skip it when the project cannot meet attribution or share-alike terms, or
  needs a conventional family with formal commercial support.

## Agent notes

- There is no npm package or coding-agent API documented for the foundry.
- Do not infer license terms across families. Read the license bundled with the
  exact font before using or modifying it.
- Ensure any attribution and license text travels with the shipped asset.
- Do not commit fonts into this documentation repository; link to the source.
