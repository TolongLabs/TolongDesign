## What it is

designmd.supply is a hosted generator and collection of reusable DESIGN.md
guides. It accepts a public website and turns visual identity into a Markdown
design reference for agents.

Public guide pages demonstrate the output and the source repository is MIT
licensed. It uses Context.dev to gather site information, so check extracted
details against the live site before client use.

## Paywall and pricing

- **Free:** Browse published guides and use the hosted generator without a paid
  plan listed.
- **Paid:** No paid plan or published charge was listed on the official site or
  repository.
- **Sign-up required?:** Public guides are viewable without signing in. The
  reviewed pages do not state whether generation requires an account.
- **Licence for client work:** MIT covers the generator repository code; it does
  not grant rights to brands, logos, or media represented in generated
  references.

Checked 2026-10-07.

## How to use

1. Choose an existing guide to learn the output structure, or enter a public URL
   in the generator. Use a site available without a login.

2. Inspect typography, palette, imagery, and layout notes. Compare them with the
   original and remove values inferred from a single screen.

3. Save the Markdown as project context and ask the coding agent to apply its
   principles with client-owned assets and copy.

## When to use it

- Use it when a team wants a simple generator and public examples without a
  catalog subscription.
- Skip it for private sources or an approved official brand spec; ask for
  official tokens instead.

## Agent notes

Generated Markdown can be used as agent context; separate extracted values from
design decisions.

The repository uses Context.dev for site context; check that service’s terms and
limits when adapting it.
