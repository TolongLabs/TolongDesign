## What it is

Aura is currently an AI website builder and visual editor that generates and
edits pages from prompts. Its product has expanded beyond the
design-system-generator description in Designeer; current materials describe
page building, code export, and Figma workflows.

The hosted app includes tutorials, templates, and design-system examples. It
targets people editing generated interfaces in a browser rather than agents
calling a public CLI or API.

## Paywall and pricing

- **Free:** The FAQ describes a trial, not a permanent free generation tier: 20
  prompts over three days, with a payment method required.
- **Paid:** The FAQ lists Pro, Max, and Ultra tiers and references Elite. Exact
  prices were not readable in the material reviewed.
- **Sign-up required?:** Yes. Trial registration requires a payment method;
  check the billing screen for renewal terms.
- **Licence for client work:** Aura is proprietary. Review current service and
  template terms for code export and client work.

Checked 2026-10-07.

## How to use

1. Use the quick-start tutorial to generate a page from a prompt or edit an
   existing project. Describe page structure, audience, and content as well as
   style.

2. Refine layout, imagery, and responsive behavior in the editor; the
   landing-page tutorial demonstrates a flow using images and video.

3. Export code or move the result into Figma, inspect the markup, and replace
   placeholder content with client assets.

## When to use it

- Use it when a designer or developer wants to explore and edit a generated page
  in a visual browser editor.
- Skip it when an agent needs a stable CLI/API or the project requires a local
  workflow with a clear software license.

## Agent notes
