## What it is

The current typeui.sh site catalogs design skills, UI prompts, animation
prompts, brand-kit material, audits, and analytics. This differs from the
Designeer blurb about scaffolding typed UI components.

Resources are intended for designers and coding agents. The site documents CLI
pulls and MCP, while plan access controls copying, downloads, and project
features.

## Paywall and pricing

- **Free:** Free accounts can explore the skill and prompt catalog.
- **Paid:** Creative is $30/month, Insights is $30/month, and All Access is
  $50/month. Annual billing includes two months free; downloads, MCP, and
  project features require a paid plan.
- **Sign-up required?:** Browsing is available; an account and paid plan are
  needed for gated downloads, MCP, or projects.
- **Licence for client work:** TypeUI is proprietary. Review terms for
  downloaded skills or prompt use in commercial work; do not redistribute paid
  materials.

Checked 2026-10-07.

## How to use

1. Browse Creative skill and prompt docs to choose a workflow, such as a
   design-system brief, UI prompt, or animation prompt.

2. Install a skill collection using the documented CLI pull command, keeping
   only relevant instructions in the project or agent scope.

3. Connect MCP if the account and plan permit it, then ask the agent for a
   design brief or audit before it edits the interface.

```bash
bunx typeui.sh pull creative
```

## When to use it

- Use it when a project needs explicit design instructions or repeatable UI
  critique for agents.
- Skip it when you need ready-made React components; use mcpcn or agentcn.

## Agent notes

The site documents a CLI package and MCP access. Check plan requirements before
pulling content or connecting.

Scope downloaded skills to the current project rather than adding unrelated
global instructions.
