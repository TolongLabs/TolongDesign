## What it is

The `x.ai/bot` URL was originally catalogued by Designeer as the technical
documentation specification for xAI's web crawler and data scraping bots.
However, xAI has since repurposed the `x.ai/bot` endpoint to host "Grok Bot"—an
autonomous AI teammate and agent platform designed to execute complex,
multi-step digital tasks.

Grok Bot functions as a virtual coworker operating on its own dedicated virtual
machine environment. Rather than simply responding with text suggestions, Grok
Bot can authenticate into web applications (such as Zendesk, Salesforce, or
internal admin dashboards), navigate user interfaces, observe user
demonstrations, and record repetitive processes into scheduled automated
routines.

Users can run multiple bots in parallel—for example, assigning one bot to sales
prospecting, another to customer support triage, and a third to competitive
research. Grok Bots maintain persistent conversational context, collaborate
within shared conversation threads, and alert human operators only when explicit
confirmation or approval is required.

## Paywall and pricing

- **Free:** No persistent free tier. Access requires an active paid
  subscription.
- **Pro:** Starts at $20/month billed monthly. Includes a dedicated Grok Bot
  virtual environment, tool authentication, scheduled routines, desktop and
  mobile apps, and weekly token allocations.
- **Pro+ / Ultra:** Higher-tier plans providing extended token quotas, priority
  inference access, and support for running multiple concurrent bots.
- **Enterprise / Government:** Custom pricing with tailored data isolation,
  dedicated infrastructure, and custom security compliance terms.
- **Sign-up required?** Yes, requires an xAI account.
- **Licence for client work:** Proprietary SaaS software. Output data generated
  by routines can be utilized internally or across client engagements.

Verified on the official x.ai/bot page on 2026-10-07.

## How to use

1. Download and install the application: Download the Grok Bot desktop client
   for macOS from `https://x.ai/bot`.
2. Authenticate and connect tools: Sign in with your xAI subscription
   credentials and grant the bot access to necessary web applications or browser
   sessions.
3. Teach a workflow: Demonstrate a repetitive operational task once while Grok
   Bot observes and records the interaction sequence.
4. Schedule automated routines: Save the demonstrated workflow as a recurring
   scheduled routine (e.g., daily bug triage or ticket summarization).
5. Monitor multi-bot collaboration: Create a shared thread with specialized
   agents to pass intermediate results across systems automatically.

## When to use it

- Use it when non-technical teams or operations staff need autonomous desktop
  agents to handle repetitive browser navigation and data entry tasks.
- Use it to schedule background monitoring and reporting routines that execute
  across third-party SaaS portals.
- Skip it when managing parallel code-generating agents in local git
  repositories; use [Dray](../agents-mcp/dray.md) instead.
- Skip it when seeking privacy-focused website analytics; explore
  [Umami](../development/umami.md).

## Agent notes

- Official URL: `https://x.ai/bot`.

  specifications, but now serves the Grok Bot desktop application.
