## What it is

Zed is a native code editor built around fast editing, project navigation,
collaboration, and optional AI features. The AI workflows include an Agent
Panel, inline assistant, edit predictions, parallel agents, MCP servers, and
external coding agents.

The Personal plan can be used without Zed-hosted AI or with a developer's own
API keys and external agents. Pro adds Zed-hosted model usage and unlimited edit
predictions. Business adds organization-level policies and billing.

The Zed repository says its source is primarily GPL-3.0-or-later, with
Apache-2.0 components where marked. Review the relevant component licences if
modifying or redistributing source.

## Paywall and pricing

- **Free:** Personal is $0 forever and includes 2,000 accepted edit predictions
  plus unlimited use with personal API keys or external agents.
- **Paid:** Pro is $10/month and includes $5 of model tokens; additional use is
  usage-billed. Business is $30 per seat/month.
- **Sign-up required?** An account is needed for Zed-hosted AI and team plans.
- **Licence for client work:** the application is open source; source
  redistribution follows the repository's GPL and component licences.
- **Checked:** 2026-10-07.

## How to use

1. Download Zed for the target operating system and open a project folder.
2. Use the editor normally, then open the Agent Panel to prompt an agent with a
   task and relevant file context.
3. Configure a hosted model, a personal provider key, an external agent, or an
   MCP server in Agent Settings.
4. Review proposed edits and use the integrated terminal and Git tools to
   inspect the result.

## When to use it

- Use it when a fast native editor and agent panel fit the team's workflow.
- Use it when the developer wants to bring their own model provider or external
  agent.
- Skip it when the team depends on an editor extension unavailable in Zed or
  requires a hosted feature only available on another plan.

## Agent notes

Zed works with built-in and external agents; configure the provider or MCP
server from Agent Settings. Personal use with an external agent is unlimited
according to the pricing page. Model-token usage is separate from edit
predictions. Check repository source licences before modifying or redistributing
Zed itself.
