## What it is

On 2026-10-07, the official endpoint returned HTTP 200 in a headless browser and
loaded a page titled “Painting Loaders.” It showed 12 named animated examples —
Garden, Dawn, Willow, Wisteria, Orchard, Irises, Poppies, Koi, Roses, Oranges,
Sail, and Dusk — with a Copy code control on each card. The footer says “Built
by Sasha” and links to the author's X profile.

The gallery and copy controls were available without signing in. The live site
did not publish a package, framework integration guide, or licence. Designeer
describes the resource as React canvas loaders, but verify the copied code and
its usage rights before adopting it in a client project.

## How to use

1. Open the gallery and choose a loader card such as Garden, Dawn, or Willow.
2. Preview the animation or open the card full screen, then use **Copy code**.
3. Inspect the copied code for its framework, dependencies, and browser
   requirements; the site publishes no package install command.
4. Confirm the author's licence before using copied code in a client project,
   then test the animation with reduced-motion and performance settings.

## When to use it

- Use it to compare hand-painted loading treatments or inspect the examples
  before deciding whether one fits the product's tone.
- Use copied code in a client build only after confirming its licence and
  framework requirements with the author.

- Skip it if you need a versioned, licensed React package; consider
  [React Bits](../component-libraries/react-bits.md) or
  [Fancy Components](../component-libraries/fancy-components.md) for verified
  React motion components.
